## 💻 快速開始 (Quick Start)

為了在本機執行原有程式，我們推薦使用現代化的 Python 套件管理器 [uv](https://github.com/astral-sh/uv) 或是傳統的 `pip` 來配置環境。

### 1. 複製本專案至本地
```bash
git clone https://github.com/roberthsu2003/machine_learning.git
cd machine_learning
```

### 2. 建立虛擬環境並安裝依賴
*   **使用 `uv`（推薦，極速）：**
    ```bash
    # 建立環境並安裝套件
    uv init --no-package
    uv venv
    uv pip install -r requirements.txt
    ```
*   **使用傳統 `pip`：**
    ```bash
    # 建立環境
    python -m venv .venv
    source .venv/bin/activate  # macOS/Linux
    # .venv\Scripts\activate   # Windows
    
    # 安裝套件
    pip install -r requirements.txt
    ```

### 3. 🤖 核心演算法實戰 (Algorithm Sandbox)
深入研究每種演算法的數學原理、程式實作以及優缺點，學會它們最適合應用於哪種數據。

> [!TIP]
> **學習建議**：不要只依賴套件，試著理解演算法背後的幾何意義與數學邏輯，這對模型調參（Hyperparameter Tuning）極有幫助。

**閱讀方式**：每條先讀「觀念」一句話，再看「適合／注意」決定用不用，最後開範例驗證。觀念口訣：**先問問題類型（分類／迴歸／分群／降維），再問資料長相（線性／非線性、特徵多少、標籤有無），最後才選演算法。**

#### 🔹 監督式機器學習 (Supervised Learning)
*   **[k-近鄰分類演算法 (k-NN)](./k近鄰分類)**：觀念——沒有訓練過程的「懶惰學習」，新樣本看身邊 k 個鄰居投票決定類別，距離常用歐氏距離。適合——資料少、邊界不規則、想快速建立 baseline。注意——特徵一定要標準化（否則大尺度特徵綁架距離）；k 太小過擬合、太大欠擬合。範例——鳶尾花分類、推薦系統的相似物品。調參——`n_neighbors`、`weights`、`p`。
*   **[簡單線性迴歸 (Simple Linear Regression)](./簡單線性迴歸)**：觀念——假設 $y$ 與 $x$ 呈直線關係 $\hat{y} = wx + b$，用最小平方法（OLS）找誤差平方和最小的線；成本函數是碗狀曲面，可用梯度下降求解。適合——單一數值特徵預測連續目標、教學迴歸起點。注意——只看 $R^2$ 會被騙，要看殘差圖有無彎曲與異方差。範例——年資預測薪資（`Salary_Data.csv`）。調參——幾乎無，重點在檢查假設。
*   **[多元線性迴歸 (Multiple Linear Regression)](./多元線性迴歸)**：觀念——$\hat{y} = w_1 x_1 + \dots + w_n x_n + b$，特徵間高度相關叫共線性，會讓係數不穩定、解釋失真。適合——多個數值／類別特徵共同預測（房價、保費、營業額）。注意——類別特徵要編碼、數值要縮放；共線性用 VIF 檢查或改用 Ridge / Lasso。範例——保險費用預測（`insurance.csv`）、福利社營業額預測。調參——正則化強度 `alpha`、特徵選取。
*   **[邏輯迴歸分類 (Logistic Regression)](./邏輯迴歸)**：觀念——名字叫迴歸、實為分類：線性分數 $z = w^\top x + b$ 經 Sigmoid $\sigma(z) = 1/(1+e^{-z})$ 壓成機率，再以 0.5（可調）為門檻分類；多分類用 Softmax。適合——二分類／多分類 baseline、可解釋性要求高（醫療、金融）。注意——輸出機率需校準；類別不平衡要調 `class_weight` 或門檻。範例——糖尿病風險評估、乳癌診斷。調參——`C`（正則化倒數）、`solver`、決策門檻。
*   **[貝氏分類器 (Naive Bayes Classifiers)](./貝氏分類)**：觀念——貝氏定理 $P(y|x) \propto P(y)\prod_i P(x_i|y)$，大膽假設「給定類別後特徵彼此獨立」，用乘法把證據組合起來；三大家族：高斯（連續）、多項式（計數）、伯努利（0/1）。適合——文本分類、垃圾郵件、資料少但特徵多的場景。注意——獨立假設 rarely 全對，但實務常意外地強；零機率問題用拉普拉斯平滑。範例——垃圾郵件分類。調參——`alpha`（平滑）、分布家族選對。
*   **[決策樹分類器 (Decision Trees)](./樹狀模型)**：觀念——用「切一刀讓混亂減少最多」遞迴分割特徵空間，切割標準是資訊增益或 Gini 不純度下降；樹越深記得越多（過擬合）。適合——需要可解釋規則、混合型特徵（數值＋類別）。注意——未剪枝的樹幾乎必過擬合，要用預剪枝（`max_depth`、`min_samples_leaf`）或後剪枝；單棵樹邊界是方塊狀，外推能力差。範例——動物分類、鐵達尼生存預測。調參——`max_depth`、`min_samples_split`、`ccp_alpha`。
*   **[決策樹集成模型 (Ensembles of Trees)](./決策樹集成模型)**：觀念——一棵樹太任性，就組一群樹投票：隨機森林用 Bagging（平行取樣、各學一部分再平均以降方差）；梯度提升（GBDT）用 Boosting（循序修正殘差以降偏差）。適合——結構化資料的預設強者（競賽、醫療、金融）。注意——隨機森林較不怕過擬合但較鈍；GBDT 強但要調學習率、樹深、早停。範例——心臟衰竭生存預測、乳癌分類。調參——`n_estimators`、`max_depth`、`learning_rate`、早停輪數。
*   **[核化支援向量機 (SVM)](./核化支援向量機)**：觀念——找一條「離兩邊都最遠」的最大邊界超平面，只由邊界上的支援向量決定；線性分不開時用核技巧把資料升到高維再切（RBF 核最常用）。適合——中小樣本、高維稀疏（文本）、邊界複雜但樣本不多。注意——一定要標準化；`C` 管容錯（大 C 硬分類、易過擬合）、`gamma` 管影響半徑（大 gamma 邊界扭曲）。範例——乳癌分類、非線性雙月資料。調參——`C`、`gamma`、`kernel`。
*   **[集成學習與薈萃式學習 (Ensemble & Stacking)](./薈萃式學習)**：觀念——集體智慧：Bagging 降方差（平行）、Boosting 降偏差（循序）、Stacking 用元模型融合不同模型的預測。適合——追求最強泛化、單一模型撞牆時。注意——複雜度與訓練成本上升，可解釋性下降；元模型要在驗證折外預測上訓練以防洩漏。範例——信用卡違約預測、心臟病 Boosting、糖尿病 Stacking。調參——基模型多樣性、元模型選擇、交叉驗證折數。

**監督式選型速查**：樣本少＋要解釋→邏輯迴歸／決策樹；文本計數→貝氏；結構化資料要最強→隨機森林／GBDT；高維小樣本非線性→SVM；單特徵連續預測→線性迴歸。

#### 🔸 非監督式機器學習 (Unsupervised Learning)
*   **[K-Means 集群演算法](./集群分析/k-means.ipynb)**：觀念——先猜 K 個中心，迭代「分配→更新中心」直到收斂，目標是群內距離平方和最小。適合——已知大概幾群、群呈圓形分布（客戶分群）。注意——K 要事先指定（用手肘法／輪廓係數選）；對初始值、離群值、不同尺度敏感，務必標準化。範例——客戶分群、圖像顏色壓縮。調參——`n_clusters`、`n_init`。
*   **[階層式集群 (Hierarchical Clustering)](./集群分析/hierarchical_clustering.ipynb)**：觀念——由下而上凝聚（或由上而下分裂），用樹狀圖（Dendrogram）記錄每一次合併，橫切一刀即得一種分群。適合——想看多層次結構、樣本量中等（基因、文件主題）。注意——樣本大時計算貴；連結法（linkage）與距離度量會改變結果。範例——物種／文件階層分群。調參——切樹高度、`linkage`。
*   **[DBSCAN 密度分群](./集群分析/dbscan.ipynb)**：觀念——密度相連即同群：核心點周圍半徑 `eps` 內夠多鄰居就向外擴張，低密度點判為雜訊。適合——形狀不規則（月牙、環形）、有雜訊要自動過濾。注意——`eps` 與 `min_samples` 難調且對尺度敏感；高維會失效（維度詛咒）。範例——地理熱點、異常點偵測。調參——`eps`、`min_samples`。
*   **[主成分分析 (PCA) 降維](./特徵工程/examples/12_pca.ipynb)**：觀念——找一組正交新軸，讓投影後變異數最大（第一主成分即資料最舒展方向），用少數主成分保留多數資訊。適合——高維視覺化（壓到 2D 畫圖）、去噪與加速、共線性緩解。注意——PCA 只看變異不管標籤，分類資訊可能被丟掉；務必先標準化；主成分不可解釋時要說明。範例——手寫數字降維視覺化、人臉特徵壓縮。調參——保留維度數／解釋變異比（如 95%）。

**非監督速查**：已知幾群且圓形→K-Means；要看層次→階層式；形狀怪＋有雜訊→DBSCAN；太高維先看→PCA。

#### 🧠 深度學習基礎 (Deep Learning)
*   **[深度學習與神經網絡](./深度學習)**：觀念——多層感知機（MLP）$ \hat{y} = W_2\,\sigma(W_1 x + b_1) + b_2 $，靠非線性激發函數（ReLU / Sigmoid / Softmax）疊出複雜邊界；正向算預測、反向傳播用鏈鎖律分攤責任、優化器（SGD / Adam）更新權重。分類用交叉熵、迴歸用 MSE。適合——影像、語音、文本等非結構化資料，或特徵需自動學出的場景。注意——結構化小資料上，隨機森林／GBDT 常更強更快；深網要配驗證集早停、Dropout、標準化輸入。範例——手寫數字辨識（MLP 入門）、 dossiers 見 [深度學習](./深度學習) 內的 TF / PyTorch 延伸。調參——學習率、隱藏層寬深、batch size、early stopping。已補上完整觀念頁：感知機→MLP、激發函數對照、反向傳播直覺、訓練除錯順序。
