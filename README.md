# 機器學習教材｜從概念到實戰

給第一次學機器學習的學生：先弄懂資料如何變成預測，再做一個完整範例。這個儲存庫也收錄演算法筆記、資料集與部署示範，作為後續查閱資料。

## 第一次來，照這個順序

1. **看入門講義**：[15 頁線上版](./docs/index.html) · [PDF](./簡報圖片/機器學習簡報.pdf)。先認識特徵、標籤、訓練、測試與預測。
2. **完成三個小專案**：[廣告效益預測](./AI提問與機器學習實戰/01_廣告效益預測_迴歸篇/README.md) → [鐵達尼號生存預測](./AI提問與機器學習實戰/02_鐵達尼號生存預測_分類篇/README.md) → [商場客戶分群](./AI提問與機器學習實戰/03_商場客戶分群_集群篇/README.md)。依序練習迴歸、分類與分群。
3. **選自己的題目**：到 [22 個實戰專案目錄](./docs/projects/index.html) 按情境挑選。每個專案先開 Notebook，再對照資料與示範應用。

> **每個專案都問自己：**要預測什麼？哪些欄位是輸入？如何檢查結果？模型在哪些情況下可能失準？

## 在本機執行 Notebook

需要 Python 3 與 Jupyter 環境。複製儲存庫後，在根目錄建立虛擬環境並安裝共用套件：

```bash
git clone https://github.com/roberthsu2003/machine_learning.git
cd machine_learning
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Windows 的啟用指令為 `.venv\Scripts\activate`。進入選定的專案資料夾後，先閱讀該專案 `README.md` 的「從這裡開始」。桌面示範程式可能還需要平台支援的圖形介面套件。
