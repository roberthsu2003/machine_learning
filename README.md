## 💻 快速開始 (Quick Start)

為了在本機執行原有程式，我們推薦使用現代化的 Python 套件管理器 [uv](https://github.com/astral-sh/uv) 或是傳統的 `pip` 來配置環境。

### 1. 複製本專案至本地
```bash
git clone https://github.com/roberthsu2003/machine_learning.git
cd machine_learning
```

### 2. 建立虛擬環境並安裝依賴
*   **使用 `uv`（推薦，極速）：**
    ```bash
    # 方法 A：直接依照 uv.lock 同步完整環境
    uv sync --locked

    # 方法 B：手動建立虛擬環境並安裝 requirements.txt
    uv venv
    uv pip install -r requirements.txt
    ```
*   **使用傳統 `pip`：**
    ```bash
    # 建立環境
    python3 -m venv .venv
    source .venv/bin/activate  # macOS/Linux
    # .venv\Scripts\activate   # Windows
    
    # 安裝套件
    pip install -r requirements.txt
    ```

### 3. 🤖 核心演算法實戰 (Algorithm Sandbox)
深入研究每種演算法的數學原理、程式實作以及優缺點，學會它們最適合應用於哪種數據。

> [!TIP]
> **學習建議**：不要只依賴套件，試著理解演算法背後的幾何意義與數學邏輯，這對模型調參（Hyperparameter Tuning）極有幫助。

**閱讀方式**：表格先讀「核心觀念」一句話，再看「適合數據・代表範例」決定用不用；調參與注意事項細節見各子章節。選演算法口訣：**先問問題類型（分類／迴歸／分群／降維），再問資料長相（線性／非線性、特徵多少、標籤有無），最後才選演算法。**

#### 🔹 監督式機器學習 (Supervised Learning)

| 演算法 | 核心觀念（一句話） | 適合數據・代表範例 |
| :--- | :--- | :--- |
| [k-近鄰分類 (k-NN)](./k近鄰分類) | 沒有訓練過程的「懶惰學習」：看身邊 k 個鄰居投票，距離常用歐氏距離 | 資料少、邊界不規則的 baseline・鳶尾花分類 |
| [簡單線性迴歸](./簡單線性迴歸) | 假設 y 與 x 呈直線關係，用最小平方法找誤差平方和最小的線 | 單一數值特徵預測連續目標・年資預測薪資 |
| [多元線性迴歸](./多元線性迴歸) | 多個特徵的線性組合；特徵高度相關叫共線性，會讓係數不穩定 | 多特徵共同預測・[醫療保險費用預測](./多元線性迴歸/multiple_linear_regression_insurance.ipynb)、[福利社營業額預測](./多元線性迴歸/學校福利社營業額預測) |
| [邏輯迴歸分類](./邏輯迴歸) | 線性分數經 Sigmoid 壓成機率再以門檻分類；多分類用 Softmax | 可解釋的分類 baseline・糖尿病風險、乳癌診斷 |
| [貝氏分類器](./貝氏分類) | 貝氏定理＋「給定類別後特徵獨立」假設，用乘法組合證據 | 文本、垃圾郵件、資料少特徵多 |
| [決策樹](./樹狀模型) | 用「切一刀讓混亂減少最多」遞迴分割，切割標準是資訊增益或 Gini 下降 | 需要可解釋規則、混合型特徵・動物分類 |
| [決策樹集成](./決策樹集成模型) | 一群樹投票：隨機森林降方差，梯度提升降偏差 | 結構化資料的預設強者・心臟衰竭生存預測 |
| [核化支援向量機](./核化支援向量機) | 找「離兩邊都最遠」的最大邊界；線性分不開用核技巧升維再切 | 中小樣本、高維稀疏・乳癌分類 |
| [集成與薈萃學習](./薈萃式學習) | 集體智慧：Bagging 平行降方差、Boosting 循序降偏差、Stacking 元模型融合 | 單一模型撞牆時・信用卡違約預測 |

> **選型速查**：樣本少＋要解釋 → 邏輯迴歸／決策樹；文本計數 → 貝氏；結構化資料要最強 → 隨機森林／GBDT；高維小樣本非線性 → SVM；單特徵連續預測 → 線性迴歸。調參細節見各子章節。

#### 🔸 非監督式機器學習 (Unsupervised Learning)

| 演算法 | 核心觀念（一句話） | 適合數據・代表範例 |
| :--- | :--- | :--- |
| [K-Means](./集群分析/k-means.ipynb) | 先猜 K 個中心，迭代「分配→更新」直到收斂 | 已知大概幾群、群呈圓形・客戶分群 |
| [階層式集群](./集群分析/hierarchical_clustering.ipynb) | 由下而上凝聚，樹狀圖橫切一刀即一種分群 | 想看多層次結構・文件主題分群 |
| [DBSCAN](./集群分析/dbscan.ipynb) | 密度相連即同群，低密度點判為雜訊 | 形狀不規則、有雜訊・地理熱點、異常偵測 |
| [PCA 降維](./特徵工程/examples/12_pca.ipynb) | 找正交新軸讓投影變異數最大，少數成分保留多數資訊 | 高維視覺化、去噪加速・手寫數字降維 |

> **選型速查**：已知幾群且圓形 → K-Means；要看層次 → 階層式；形狀怪＋有雜訊 → DBSCAN；太高維先看 → PCA。

#### 🧠 深度學習基礎 (Deep Learning)

| 演算法 | 核心觀念（一句話） | 適合數據・代表範例 |
| :--- | :--- | :--- |
| [深度學習與神經網絡](./深度學習) | MLP 靠非線性激發函數疊出複雜邊界；正向算預測、反向傳播分攤責任、優化器更新權重 | 影像、語音、文本・手寫數字辨識入門 |
