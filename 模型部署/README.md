# 🚀 機器學習模型部署專案目錄 (Machine Learning Model Deployment)

本目錄收錄了將機器學習模型從演算法訓練走向雲端 Web 服務的完整實戰專案，架構均採用 **FastAPI (高效 RESTful API)** 與 **Gradio (低代碼互動 Web UI)** 混合掛載技術。
