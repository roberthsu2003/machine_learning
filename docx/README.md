# 機器學習課程網頁

Light Mode 靜態網頁入口：[index.html](./index.html)。直接在瀏覽器開啟即可使用，無須安裝套件。

正式網址：<https://roberthsu2003.github.io/machine_learning/docx/>

將檔案上傳至 GitHub 後，在專案 **Settings → Pages → Build and deployment** 選擇 **Deploy from a branch**，選取包含這些檔案的分支與 **/(root)**，再儲存。部署完成後，上述網址才會生效。

網頁的 PDF 與 PowerPoint 按鈕使用相對路徑，連到 `簡報圖片` 中的既有教材。請保留兩個資料夾的相對位置。`docx` 是網頁資料夾名稱，並非 Word 檔案格式。
