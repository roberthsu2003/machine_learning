# 🧠 深度學習基礎 (Deep Learning)

> **這一節要回答：線性模型不夠用時，如何讓模型自己學出特徵？**

## 2. 核心觀念

### 2.1 從感知機到 MLP：為什麼要「深」又要「非線性」？

* **單一感知機**：$ \hat{y} = \sigma(w^\top x + b) $，只能切出線性邊界（只能解 OR，不能解 XOR）。
* **多層感知機 (MLP)**：$\hat{y} = W_2 \, \sigma(W_1 x + b_1) + b_2$。關鍵是中間的**非線性激發函數** $\sigma$——沒有它，疊再多層也只是線性變換。
* **萬能近似直覺**：夠寬的單隱藏層 MLP 可逼近任何連續函數；「深」則讓模型用更少參數組合出階層式特徵（邊 → 紋理 → 物件）。

### 2.2 激發函數：什麼時候用誰？

| 函數 | 公式 | 特性與用途 |
| :--- | :--- | :--- |
| Sigmoid | $\sigma(z) = \frac{1}{1+e^{-z}}$ | 輸出 (0,1)，曾用於二分類輸出；深層易梯度消失，隱藏層少用 |
| Tanh | $\tanh(z)$ | 輸出 (−1,1)，零中心，比 Sigmoid 好一點；深層仍有消失問題 |
| ReLU | $\max(0, z)$ | 隱藏層預設首選，計算快、緩解消失；注意「死亡 ReLU」（可用 Leaky ReLU） |
| Softmax | $\frac{e^{z_i}}{\sum_j e^{z_j}}$ | 多分類輸出層，輸出是合計為 1 的機率（見 [邏輯迴歸](../邏輯迴歸) 的多類延伸） |

### 2.3 損失函數：迴歸與分類用不同的尺

* **迴歸**：MSE $ \frac{1}{n}\sum (y - \hat{y})^2 $（見 [簡單線性迴歸](../簡單線性迴歸) 的成本函數）。
* **二元分類**：二元交叉熵 $ -\big[y \log \hat{p} + (1-y)\log(1-\hat{p})\big] $；多分類用分類交叉熵 + Softmax。
* **觀念**：損失函數就是「模型犯錯的計分板」，優化器的工作是把它壓低。

### 2.4 反向傳播：一句話講懂

* **正向傳播**算出預測與損失；**反向傳播**用鏈鎖律把「每一層要負多少責任」從輸出往回傳：$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial h} \cdot \frac{\partial h}{\partial W_1}$。
* 生活比喻：考試考差了，先怪最後一題的粗心，再往回追是哪個環節的觀念沒學好——責任按「影響程度」分攤，這就是梯度。
* 實務上由框架自動微分完成；學生要懂的是「**梯度會消失／爆炸**」：層越深，連乘越多，Sigmoid 層容易把梯度越乘越小（改用 ReLU + 好的初始化 + 正規化可緩解）。

### 2.5 訓練實務：讓網路真的學會

* **優化器**：SGD（加動量）→ Adam（預設首選，學習率常用 1e-3 起跳）。學習率太大發散、太小學不動。
* **防止過擬合**：資料多最有效；其次用驗證集早停 (Early Stopping)、Dropout、權重衰減 (L2)、資料增強。
* **正規化輸入**：特徵標準化是深度學習的標準前菜（見 [特徵工程](../特徵工程)）。
* **除錯順序**：先讓模型在小批量上過擬合（確認容量夠）→ 再加正規化 → 再調學習率與架構。

## 4. 常見誤解

| 誤解 | 正確觀念 |
| :--- | :--- |
| 層越多一定越好 | 資料少時深網路更容易過擬合；先從淺而寬的 baseline 開始 |
| 準確度 99% 就是好模型 | 先看基準率與驗證方式（見 [評估指標](../評估指標)）；不平衡資料要看 Precision / Recall / AUC |
| 深度學習不用特徵工程 | 結構化資料上，好的特徵與 gradient boosting 常比 MLP 更強；影像／語音／文本才是深度學習主場 |
| 反向傳播很神秘 | 它就是鏈鎖律 + 梯度下降，只是規模大；除錯重點在學習率、初始化與資料管線 |
