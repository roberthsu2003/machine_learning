## 特徵選擇的計算與閱讀

三種方法使用相同的 32 筆固定、已標準化的示範資料（訓練 16 筆、驗證 16 筆），不再共用相關係數排名。

- 過濾：只從訓練集計算每欄與 y 的 |Pearson r|，保留排名前 k 欄。
- 包裝：枚舉全部 k 欄組合；每組在訓練集擬合線性回歸，計算驗證 MSE，全部評估後選出誤差最低者。每三步完成一組評估。驗證集用來選擇特徵，因此其分數不代表獨立測試成績。
- 嵌入：用座標下降實算 Lasso，目標為訓練 MSE / 2 + α × Σ|係數|。播放呈現 α 從 0 到指定強度的正則化路徑，每個 α 都重新擬合；這不是單次訓練的時間軸。非零係數決定保留哪些特徵，與 k 無關。

資料刻意包含訓練集的弱假關聯 X2，讓包裝法的驗證比較與 Lasso 的係數收縮可以辨識。這是教材固定範例，結果不代表所有資料都會選到相同欄位。Lasso 目標與座標下降依據 [scikit-learn 官方文件](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Lasso.html)。

## 特徵縮放：先理解為什麼

Canvas 2D 以查詢房屋 Q（600 m²、3 房）比較 A（610 m²、6 房）與 B（800 m²、3 房）。未縮放時，A 的距離約 10.44，B 為 200，面積數值主導比較；標準化或 Min-Max 後，本例中 B 較近。橘色／紫色長條分別表示面積差平方與房間差平方，其總和是 d²，不能把它們當成可直接相加的歐氏距離 d。長條各圖使用自己的比例尺，只能在同圖內比較。

四步播放依序呈現訓練統計、逐欄轉換、計算距離、比較近鄰。六筆固定訓練資料含 A、B，Q 不參與 fit；離群值勾選後增加一筆 5000 m²、3 房的訓練樣本。兩欄各自計算均值、母體標準差或最小／最大值。

面積改以千平方公尺表示時，物理房屋沒有改變，但未縮放的兩候選排名會反轉；Z-score 和 Min-Max 的距離與排名則不受這種單位換算影響。這說明數值尺度不應自動變成特徵的重要性。縮放影響 KNN、K-means 等距離模型；並不保證準確率提高，決策樹通常不需要縮放。教材概念依據 [scikit-learn 特徵縮放範例](https://scikit-learn.org/stable/auto_examples/preprocessing/plot_scaling_importance.html)。

## 類別編碼：有序不是等距

有序模式預設以大學示範，四步呈現指定高中 < 大學 < 碩士的語義順序、對應 0／1／2、游標沿階梯移動、讀取所選編碼。三個等級與代碼同時保留，選取等級在終點以橘框標示。階梯高度只用來表達排名，不代表學歷、能力或年數的量，整數間隔也不能證明原始等級差距相等。若模型將整數當成連續數值，仍可能引入等距假設。

順序需要由領域語義明確指定；實際使用 [OrdinalEncoder](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.OrdinalEncoder.html) 時，應提供符合語義的類別順序，而不是只依賴自動排序。無序模式比較完整三欄 One-Hot 與整數：前者不同類別向量的歐氏距離均為 √2；後者刻意展示人為的大小與距離關係。
