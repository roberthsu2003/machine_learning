## 特徵選擇的計算與閱讀

三種方法使用相同的 32 筆固定、已標準化的示範資料（訓練 16 筆、驗證 16 筆），不再共用相關係數排名。

- 過濾：只從訓練集計算每欄與 y 的 |Pearson r|，保留排名前 k 欄。
- 包裝：枚舉全部 k 欄組合；每組在訓練集擬合線性回歸，計算驗證 MSE，全部評估後選出誤差最低者。每三步完成一組評估。驗證集用來選擇特徵，因此其分數不代表獨立測試成績。
- 嵌入：用座標下降實算 Lasso，目標為訓練 MSE / 2 + α × Σ|係數|。播放呈現 α 從 0 到指定強度的正則化路徑，每個 α 都重新擬合；這不是單次訓練的時間軸。非零係數決定保留哪些特徵，與 k 無關。

資料刻意包含訓練集的弱假關聯 X2，讓包裝法的驗證比較與 Lasso 的係數收縮可以辨識。這是教材固定範例，結果不代表所有資料都會選到相同欄位。Lasso 目標與座標下降依據 [scikit-learn 官方文件](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Lasso.html)。
