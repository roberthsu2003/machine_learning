## 動畫與操作設計

| 場景 | 要看見的幾何動畫 | 學生／教師操作 |
| :--- | :--- | :--- |
| 特徵選擇 | 多欄方塊矩陣中，無關特徵淡出；過濾、包裝與嵌入方法用不同選取流程對照。 | 切換方法、保留／移除特徵 |
| 特徵縮放 | 散點與座標軸從尺度懸殊變成縮放後的空間；距離線與數值同步更新。 | 原始／Z-score／Min-Max、加入離群值 |
| 類別編碼 | 顏色方塊分別變成整數標籤或 One-Hot 向量；對照有序與無序資料。 | 切換編碼、選類別、展開向量 |
