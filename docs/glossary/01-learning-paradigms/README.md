## 動畫與操作設計

| 場景 | 要看見的幾何動畫 | 學生／教師操作 |
| :--- | :--- | :--- |
| 監督式：分類與回歸 | 帶標籤的圓點流入模型；切換後分別顯示分類邊界與回歸線。 | 切換分類／回歸、顯示／隱藏標籤、加入新樣本 |
| 非監督式：聚類與降維 | 無標籤圓點逐輪分群，中心點移動；另以投影線展示 2D → 1D 的降維。 | 一步分群、重設中心、旋轉投影方向 |
| 範式比較 | 同一批資料在「有標籤／無標籤」兩條管線移動，對照模型接收的資訊。 | 切換範式、逐步播放；半監督與強化學習以補充示意呈現 |
