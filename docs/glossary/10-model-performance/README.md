## 動畫與操作設計

| 場景 | 要看見的幾何動畫 | 學生／教師操作 |
| :--- | :--- | :--- |
| 欠擬合、良好擬合與過度擬合 | 同一批散點上，直線、平滑曲線與追逐雜訊的曲線逐步切換。 | 調整模型複雜度、顯示訓練／驗證點 |
| 偏差與變異數 | 用固定資料生成機制重抽訓練樣本，多條模型線比較平均偏差與模型波動。 | 重抽樣本、調整複雜度、顯示平均模型 |
| 學習曲線與早停 | 訓練／驗證曲線隨時間延伸，游標走過驗證最佳點，顯示繼續訓練的變化。 | 播放訓練、暫停、早停／繼續 |
| 改善方式 | 新增資料、減少容量或正則化後，模型線與誤差對照更新。 | 比較改善方法、顯示適用條件 |

## 驗收重點

- 能直接從本章網址進入，不依賴先打開總目錄。
- 動畫真的改變幾何位置、形狀、邊界或路徑，文字與數值同步解釋。
- 播放、暫停、重設與單步控制都能用；可重現相同資料與結果。
- 保留原教材的章節順序與中文名稱，導覽提供上一章／目錄／下一章。
- 計算結果與公式一致；純機制示意、預先設定數值與實際演算法清楚區分。
- Light Mode、手機版、鍵盤操作與無動畫文字說明皆可用。
