## 動畫與操作設計

| 場景 | 要看見的幾何動畫 | 學生／教師操作 |
| :--- | :--- | :--- |
| Bagging | 樣本有放回抽取到不同模型；多個預測標記移向投票或平均結果。 | 重新抽樣、顯示重複樣本、逐模型投票 |
| Boosting | 弱模型依序出現，殘差線段進入下一輪；模型曲線逐輪加總。 | 新增一輪、顯示殘差、調整步長 |
| Stacking | 基礎模型的 OOF 預測方塊重排為新矩陣，再流入元模型。 | 逐折產生 OOF、組成新特徵、執行元模型 |
