# 共用網頁與動畫資源

12 章使用同一套 Light Mode 版面與 Canvas 2D 播放器。

- `lesson.css`：章節導覽、互動舞台、手機與列印樣式。
- `player.js`：播放、暫停、重設、單步、倍速、時間軸與放大；離開畫面暫停。
- `geometry.js`：圓點、方塊、箭頭、座標、曲線、移動插值與繪圖工具。
- `math.js`：資料切分、KNN、K-Means、線性／多項式擬合、決策樹、梯度更新與評估指標。
- `fitting.js`：模型曲線、訓練／驗證樣本與誤差比較。
- `scene.js`：場景與參數控制的定義工具。

每章 `lesson.js` 載入自己的 `scenes/index.js`；上一章／目錄／下一章由 `build.py` 根據 `chapters.json` 產生。所有程式與圖片使用相對路徑，可直接在 GitHub Pages 發布。

時間軸只控制過程顯示；倍速不改變計算規則。預設數據或概念動畫在場景說明中標明「示意」，數值場景使用實際計算結果。原教材圖片在對應小節可展開查看。
