# 📊 機器學習常用圖表繪製指引

在機器學習專案中，**數據視覺化**是溝通、分析與診斷模型的核心工具。這些圖表主要可以分為兩個大類：**探索性數據分析 (EDA)** 與 **模型評估與診斷 (Evaluation)**。

本單元收集並實作了多種常見的機器學習圖表，幫助您在開發過程中快速查閱與使用。

## 這一章要學會的是讀圖與判斷

每份 Notebook 的程式儲存格前都有「觀念說明」：先看這一步要回答什麼問題，再執行並觀察結果。套件安裝、中文字型設定、資料準備與模型診斷各有不同用途，不能把程式跑完當成已經評估模型。

建議採用以下方式上課，學生可以請 AI 操作程式，用自己的話驗收結果：

1. **先問問題**：畫圖前說出「我想知道什麼」，例如模型漏掉哪些類別，而非先選顏色。
2. **指出證據**：說清楚一個點、柱、格子或陰影代表什麼，指出實際數值或形狀。
3. **提出下一步**：根據證據決定要查資料、改特徵、比較模型，還是取得更多資料。
4. **一次改一件事**：讓 AI 改分箱數、樹深等單一設定，先預測圖會怎麼變，再重跑比較。

學生完成時，請他回答：「我看見什麼？它可能表示什麼？我還不能下什麼結論？下一步如何驗證？」本章的示例有些只有資料探索、有些使用合成資料或訓練集展示；只有獨立評估才能提供未見資料表現的證據。

| 要回答的問題 | 選哪張圖 | 看完可提出的下一步 |
| :--- | :--- | :--- |
| 年資是否提供預測薪資的線索？ | 散佈圖 | 試做回歸並比較基準，不能直接宣布因果 |
| 特徵集中在哪裡，是否有長尾？ | 直方圖／KDE | 查少見值與分布差異，不要求所有特徵常態 |
| 群組的中心、分散與極端值是否不同？ | 箱形圖 | 查證極端值的來源，不直接刪掉 |
| 特徵是否可能重複提供資訊？ | 相關係數熱力圖 | 用驗證資料比較保留／移除特徵的影響 |
| 哪種錯誤最多、代價最高？ | 混淆矩陣 | 檢查類別指標與錯誤案例，必要時在驗證集調門檻 |
| 模型如何切開特徵平面？ | 決策邊界／meshgrid | 看邊界與樣本的關係，再另做未見資料評估 |
| 模型是否有規律地高估或低估？ | 殘差圖 | 比較特徵或模型，檢查獨立驗證誤差 |
| 補資料還是調模型較值得先試？ | 學習曲線 | 同看訓練與驗證線，再選一個方向比較 |

## 🔍 1. 探索性數據分析 (EDA) 常用圖表

在建立模型之前，我們需要透過視覺化來理解數據的結構、分佈與特徵間的關係。

| 圖表類型 | 主要用途 | 實作範例 / 連結 |
| :--- | :--- | :--- |
| **散佈圖 (Scatter Plot)** | 觀察兩個變數之間的關聯性、特徵分佈或群集特徵。 | [散佈圖實作](./scatter_plot散佈圖.ipynb) 📈 |
| **直方圖與密度圖 (Histogram & KDE)** | 觀察單一特徵的數值分佈情形、偏態（Skewness）與峰度。 | [直方圖與密度圖實作](./histogram_kde_直方圖與密度圖.ipynb) 📊 |
| **特徵相關性熱力圖 (Correlation Heatmap)** | 呈現線性相關，找出可能重複提供資訊的特徵。 | [相關係數熱力圖實作](./correlation_heatmap_相關係數熱力圖.ipynb) 🌡️ |
| **箱形圖 (Box Plot)** | 比較中位數、四分位距、鬚線與離群點；鬚線不一定是全體極值。 | [箱形圖實作](./boxplot_箱形圖.ipynb) 📦 |

> [!TIP]
> **探索數據的最佳實踐**：進行 EDA 時，建議先用 **散佈圖** 觀察特徵之間的幾何分佈，再搭配 **熱力圖** 找出可能重複提供資訊的特徵；是否保留或移除，需用模型與驗證資料比較。

## 🎯 2. 模型評估與診斷常用圖表

模型訓練完成後，我們需要藉由特定的圖表來診斷模型效能、分析誤差或優化超參數。

| 圖表類型 | 主要用途 | 實作範例 / 連結 |
| :--- | :--- | :--- |
| **混淆矩陣 (Confusion Matrix)** | 呈現分類模型在各類別上的預測正確與錯誤分佈。 | [混淆矩陣實作](./混淆矩陣confusion_maxtrix.ipynb) 🧮 |
| **決策邊界 (Decision Boundary)** | 視覺化分類器在特徵空間中的切割邊界（搭配 Meshgrid）。 | [決策邊界實作](./meshgrid說明.ipynb) 🗺️ |
| **ROC 曲線與 AUC (ROC-AUC Curve)** | 評估二分類模型在不同判定閾值下的真陽性率與偽陽性率關係。 | [ROC 曲線與 AUC](../評估指標/auc_roc_curve.ipynb) 📉 |
| **殘差圖 (Residual Plot)** | 觀察系統性高估／低估、非線性與誤差幅度變化的線索。 | [殘差圖實作](./residual_plot_殘差圖.ipynb) 📉 |
| **學習曲線 (Learning Curve)** | 繪製訓練與驗證分數隨樣本數的變化，診斷 Overfitting / Underfitting。 | [學習曲線實作](./learning_curve_學習曲線.ipynb) 📈 |

> [!IMPORTANT]
> **如何選擇評估圖表**：
> - 對於**分類模型**，優先檢視 **混淆矩陣** 了解各類別的具體誤判情況，並利用 **ROC-AUC 曲線** 評估整體分類能力。
> - 對於**迴歸模型**，可用 **殘差圖** 找出偏差、彎曲與誤差幅度變化；不能只靠它證明常態性、獨立性或所有模型假設成立。
