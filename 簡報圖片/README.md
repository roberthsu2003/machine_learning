# 📊 何謂 AI、機器學習與深度學習？

本單元主要說明人工智慧（AI）、機器學習（ML）與深度學習（DL）的核心概念與其相互關係，並提供完整的簡報檔案供下載學習。

---

## 💡 核心觀念簡介

人工智慧、機器學習與深度學習是層層包覆的關係（如同一套同心圓）：

```
┌──────────────────────────────────────────────┐
│  人工智慧 (Artificial Intelligence, AI)       │
│  （使電腦展現人類智慧的廣義技術）              │
│                                              │
│   ┌──────────────────────────────────────┐   │
│   │  機器學習 (Machine Learning, ML)      │   │
│   │  （從數據中自主學習規律以進行預測）   │   │
│   │                                      │   │
│   │   ┌──────────────────────────────┐   │   │
│   │   │  深度學習 (Deep Learning, DL) │   │   │
│   │   │  （模仿大腦多層神經網絡架構）│   │   │
│   │   └──────────────────────────────┘   │   │
│   └──────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

1. **人工智慧 (AI)**：
   * **定義**：最廣義的定義，指任何讓電腦展現出人類智慧或行為的技術。
   * **範圍**：除了機器學習外，也包含傳統的「專家系統（Rule-based Systems）」、「搜尋演算法」等寫死規則的程式。
2. **機器學習 (ML)**：
   * **定義**：AI 的一個分支技術。我們**不直接撰寫死板的規則**，而是給予電腦大量數據，讓電腦自主從中「學習」特徵與規律，並建立預測模型（例如：預測房價、過濾垃圾郵件）。
3. **深度學習 (DL)**：
   * **定義**：機器學習中的一個特殊子領域。它透過**多層的人工神經網路（Artificial Neural Networks）**結構來處理高維度、複雜的數據，特別擅長影像辨識（CNN）、自然語言處理（Transformer/LLM）等任務。
