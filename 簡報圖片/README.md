# 機器學習，從資料到預測

這份 15 頁學生講義以房價預測為主線，每頁只回答一個問題。適合初學者先理解流程，再進入專案範例。

## 學習路線

1. **概念地圖（第 1–4 頁）**：課程目標、學習順序、AI／ML／DL 與生成式 AI、機器學習和手寫規則的差異。
2. **模型流程（第 5–13 頁）**：分類與迴歸、特徵與標籤、訓練與測試資料、模型訓練、兩種問題範例、評估、多特徵與新資料預測。
3. **動手預測（第 14–15 頁）**：先估計 72 坪房價，再用 Python 計算並討論預測限制。

講義保留學生現階段必需的概念。AI 發展史、AGI、硬體規格與數學工具清單已從主線移除。第 7 頁補上資料分割，第 11 頁補上如何檢查預測表現。
