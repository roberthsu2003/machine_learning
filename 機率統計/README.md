# 機率統計：用資料說話前，先學會描述不確定性

> **這一章要回答：模型說「90% 是貓」「平均 20 分鐘送到」，我們該相信多少？**
>
> 機率統計是機器學習描述**不確定性**的語言。本章全部使用**教學合成資料**，重點是讀懂圖、問對問題，不把範例數字當成真實模型成效。

## 如何使用本章

1. **先讀「為什麼做／怎麼看」，再執行程式格。**
2. **先寫下預期，再看圖驗證。** 每格都有「先想一想」。
3. **用三句話收尾：** 我看見的證據 → 我提出的解釋 → 我不能下的結論。
4. 需要套件時請老師協助準備：NumPy、pandas、SciPy、Matplotlib、Seaborn。

每份教材共用同一套設計：繁體中文、米白底 `#F5F7F2`、墨綠 `#2F6657` 為主色、橘色標重點、固定隨機種子方便全班比較。

## 一張圖記住本章

```text
隨機變數
├── 離散：可以一一列出 → PMF（柱高＝機率，總和＝1）
│   ├── 一次二元：伯努利（貓／非貓 90%）
│   ├── 一次多類：類別分布（貓／狗／兔 70/20/10%）
│   └── 重複計數：二項分布 Bin(n, p)（5 球進 3 球？）
│
└── 連續：區間內無限多值 → PDF（面積＝機率，單點＝0）＋ CDF（P(X≤x)）
    ├── 常態 N(μ, σ²)：μ 搬中心，σ 管寬窄
    ├── 均勻 U(a, b)：等長區間機率相同，機率＝長度比
    └── 檢查形狀：Q-Q 圖＋檢定（參照選錯，判讀全錯）
```

## 學生最容易誤解的 6 件事

| 誤解 | 正確觀念 | 出處 |
| --- | --- | --- |
| 平均數就是典型的一筆 | 平均數怕極端值；看典型用中位數，看風險用標準差 | 01 |
| 抓到九成瑕疵＝九成警報是真的 | 前者是 recall，後者是 precision；基準比例會大幅改變答案 | 01 |
| PMF 柱高和 PDF 高度一樣 | PMF 柱高是機率；PDF 高度是密度，可 >1，機率要算面積 | 02、04 |
| `size` 變大就是 `n` 變大 | 二項的 `n` 是每組做幾次，`size` 是做幾組 | 03 |
| 標準化後就會變常態 | Z-score 只改尺度；右偏標準化後仍右偏 | 05、07 |
| p > 0.05 代表證明是常態 | 只是「未拒絕」；Q-Q 圖偏離也可能是參照選錯 | 08 |

## 名詞速查（本章用到的）

- **隨機變數**：把隨機結果寫成數字，如骰子點數、身高。
- **PMF**：離散每個值的機率，全部加起來為 1。
- **PDF / CDF**：連續的密度與累積機率；區間機率＝CDF 相減＝PDF 面積。
- **期望值／變異數／標準差**：中心位置、分散程度（標準差與原始單位相同）。
- **條件機率／貝氏更新**：改變分母重算機率；基準比例不同，結論完全不同。
- **Q-Q 圖**：排序後的資料 vs 理論分位數；沿直線＝形狀相符，不必是 y=x。
