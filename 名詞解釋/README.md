## 💡 本教程閱讀建議
1. **零基礎初學者**：建議按照 `01 ➔ 12` 的編號循序漸進閱讀，各章均有生動的生活比喻與觀念圖解，可快速建立扎實的心智模型。
2. **面試複習與實戰查閱**：每一章末尾皆有「📌 本章精華速記」與「特性對照表格」，可直接跳至對應主題快速複習高頻考點與常見陷阱。
3. **專案開發啟動**：在動工新專案前，推薦直接研讀 [第 12 章：機器學習訓練過程](./12_機器學習訓練過程/README.md) 中的「實戰黃金檢查清單」。
