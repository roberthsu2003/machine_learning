# 8. 集成學習 (Ensemble Learning)

集成學習（Ensemble Learning）是一種「結合眾人智慧」的強大機器學習策略。其核心思想是：**將多個弱學習器（Weak Learners，如多棵簡單決策樹）組合起來，構成一個預測能力極強的強學習器（Strong Learner）**，以獲得比任何單一模型都更優異且更穩定的泛化表現。

---

### Bagging (Bootstrap Aggregating，裝袋法)

**描述**：  
通過「自助抽樣 (Bootstrap)」從原始數據中有放回地抽取多個子集，**並行 (Parallel)** 訓練多個互不干擾的基礎模型，最後將所有模型的預測結果進行「多數投票（分類）」或「平均計算（回歸）」來完成最終決策。

![Bagging裝袋法原理與隨機森林流程](images/01_bagging.png)

**代表算法**：  
**隨機森林 (Random Forest)**（在 Bagging 基礎上更進一步，每次節點分裂時隨機挑選特徵子集，增加樹與樹之間的多樣性）。

**運作方式**：
1. **自助抽樣 (Bootstrap)**：從原始數據集中有放回地隨機抽取多個大小相同的子數據集。
2. **獨立並行訓練**：在每個子數據集上各自獨立訓練一個基礎模型（通常為未剪枝的深度決策樹）。
3. **聚合投票 (Aggregate)**：
   - 分類問題：各模型投票，少數服從多數。
   - 回歸問題：各模型預測值取算術平均。

**核心特點與優勢**：
- **有效降低變異數 (Variance)**：顯著緩解單一模型容易過擬合（Overfitting）的問題，模型表現極為穩健。
- **支援極速並行計算**：各個基礎模型之間毫無相依性，能充分發揮現代多核心 CPU/GPU 的硬體加速潛力。
- **對雜訊與異常值魯棒**：少數雜訊點只會影響極少數模型，不會撼動整體的聚合投票結果。

### Boosting (提升法)

**描述**：  
一種**串行 (Sequential，循序)** 迭代的集成技術。每個新模型都不是獨立訓練的，而是專門針對前一個模型「預測錯誤或殘差較大」的樣本進行針對性強化訓練，步步為營，逐步將多個弱學習器提升為極具競爭力的強學習器。

![Boosting提升法原理與殘差學習](images/02_boosting.png)

**代表算法**：  
**AdaBoost**、**梯度提升機 (Gradient Boosting / GBDT)**、**XGBoost**、**LightGBM**、**CatBoost**。

**運作方式**：
1. **訓練初始模型**：在原始數據上訓練第一個基礎學習器。
2. **計算誤差並專注弱點**：
   - *AdaBoost 視角*：提高先前被分類錯誤樣本的抽樣權重，讓後續模型被迫專注攻克難題。
   - *Gradient Boosting 視角*：計算模型預測與真實標籤之間的「殘差 (Residuals)」，並以新模型去擬合這些殘差。
3. **加權組合**：反覆迭代多輪，最後根據各模型的驗證表現進行加權線性組合：  
   $$\text{Final Prediction} = \sum_{t=1}^{T} \alpha_t \cdot h_t(x)$$

**直觀比喻：錯題本複習法**：  
就像學生做模考，第一次做錯的題目會標記在「錯題本」中，下次複習時針對錯題投入 80% 的精力狂練，反覆修正知識盲區，最終成為全能學霸。

**核心特點與優勢**：
- **有效降低偏差 (Bias)**：專門攻克極端困難樣本與複雜非線性關係，模型預測精準度通常高於 Bagging。
- **訓練相依性強**：由於後一個模型依賴前一個模型的輸出，無法進行大規模時間並行訓練。
- **對雜訊與離群值較敏感**：若數據中包含錯誤標籤，模型可能會過度沉迷於硬背這些異常錯題。

### Stacking (堆疊泛化法)

**描述**：  
一種多層次（Multi-level）的模型融合架構。它通常在第一層組合**多種不同演算法類型（異質模型，如 KNN、SVM、隨機森林）**，並使用第二層的「元學習器 (Meta-Learner)」來學習如何以最佳方式綜合這些模型的預測結果。

![Stacking堆疊法原理與元學習架構](images/03_stacking.png)

**運作方式**：
1. **第一層訓練 (Level-0 基礎學習器)**：訓練多個不同特性的異質算法（如 SVM 擅長邊界、隨機森林擅長非線性規則、KNN 擅長局部相似性）。
2. **生成元特徵 (Meta-Features)**：將這群第一層專家模型對訓練數據輸出的預測機率或數值，重新打包為一張全新的特徵矩陣。
3. **第二層決策 (Level-1 元學習器)**：訓練一個頂層模型（通常使用較簡單平滑的模型，如邏輯回歸 Logistic Regression），學習各專家的可信度權重並做出終極判決。

**核心特點與優勢**：
- **集百家之大成**：打破單一算法的先天盲點，結合不同架構演算法的獨特長處，是各類 Kaggle 數據競賽制勝的王牌武器。
- **防範資料洩漏 (Data Leakage)**：實務上第一層產生元特徵時，必須嚴格採用 **K 折交叉驗證 (K-Fold Out-of-fold)** 生成預測值，嚴禁讓第二層模型直接看到訓練集的標籤。
- **計算複雜度較高**：需維護訓練多種異質框架，工程維護與推論延遲較大。
