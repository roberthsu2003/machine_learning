# 7. 常見算法 (Common Algorithms)

---

### K-近鄰 (K-NN, K-Nearest Neighbors)

**描述**：  
一種基於「距離度量」的非參數化分類與回歸算法。其核心哲學是「物以類聚」——當要預測一個未知樣本時，找出特徵空間中離它最近的 $K$ 個鄰居，並以「少數服從多數」的多數表決（分類）或平均值（回歸）作為預測結果。

![K-近鄰算法原理：少數服從多數的鄰居表決](images/01_knn.png)

**特點**：
- **直觀易懂**：無需假設數據分布，邏輯非常簡單清晰。
- **懶惰學習 (Lazy Learning)**：訓練階段幾乎不做計算（僅儲存數據），所有計算都在推論預測時發生。
- **對多分類天然友善**：可直接應用於多元分類問題。
- **缺點**：當數據量大時，每次推論都要計算與所有樣本的距離，計算成本極高；且易受維度災難（Curse of Dimensionality）與局部雜訊影響。

**關鍵超參數與設定**：
- **k 值**：選擇參考的鄰居數量。
  - $k$ 過小（如 $k=1$）：容易受到單一雜訊或極端值干擾，模型過度擬合（Overfitting）。
  - $k$ 過大：決策邊界過於平滑，容易受到樣本類別不平衡干擾，導致欠擬合（Underfitting）。
- **距離度量**：常用歐氏距離（Euclidean Distance）、曼哈頓距離（Manhattan Distance）、閔可夫斯基距離（Minkowski Distance）等。

### 決策樹 (Decision Tree)

**描述**：  
一種基於樹狀階層結構的預測模型。模型從根節點（Root）出發，透過對特徵進行一系列「若條件成立則走左分支，否則走右分支」的二元或多元判斷，最終在葉節點（Leaf）輸出分類標籤或回歸預測值。

![決策樹原理：階層式條件規則與空間軸向劃分](images/02_decision_tree.png)

**特點**：
- **白盒模型 (White-box Model)**：可解釋性極高，樹狀規則可直接轉為業務邏輯（If-Else 規則）。
- **非線性表達力強**：天然支援非線性關係，能自動捕捉特徵之間的交互作用。
- **預處理需求低**：對數據尺度不敏感，通常不需要進行特徵標準化或歸一化。
- **缺點**：若不加限制，樹會無限生長直到完美記住訓練資料，極易發生嚴重的過擬合（Overfitting）。

**幾何視角**：  
在特徵空間中，決策樹的每一次分割都相當於一條平行於座標軸的切線，將空間切割為許多正交的矩形超立方體區域。

**關鍵超參數（控制樹結構以防止過擬合）**：
- **最大深度 (`max_depth`)**：限制樹的最大層數，避免模型過於複雜。
- **最小樣本分割 (`min_samples_split`)**：內部節點必須具備的最少樣本數才允許繼續分支。
- **最小葉節點樣本數 (`min_samples_leaf`)**：葉節點所必須包含的最低樣本數量。

### 支援向量機 (SVM, Support Vector Machine)

**描述**：  
一種追求「最大化間隔（Maximum Margin）」的強大分類與回歸算法。SVM 的目標是在特徵空間中找到一個最佳決策超平面（Hyperplane），使得兩類樣本距離該超平面最近的點（即「支援向量」）之間的幾何間距達到最大。

![支援向量機原理：最大間隔超平面與核技巧](images/03_svm.png)

**特點**：
- **魯棒性強**：最終決策邊界完全由少數幾顆關鍵的「支援向量 (Support Vectors)」決定，遠處樣本點的移動不會影響邊界。
- **適合高維空間**：即便特徵維度遠大於樣本數（如基因數據、文本特徵），SVM 依然表現穩健。
- **核技巧 (Kernel Trick)**：當低維數據線性不可分時，可透過核函數隱式將樣本映射至高維特徵空間，轉化為線性可分問題。
- **缺點**：樣本數量極龐大時計算與記憶體開銷較高，且模型對特徵尺度極為敏感（必須嚴格進行特徵縮放）。

**關鍵超參數**：
- **C 參數 (正則化參數)**：
  - $C$ 較大：懲罰錯誤分類嚴重，邊界較窄，容易過擬合。
  - $C$ 較小：容忍部分樣本落入間隔內，邊界較寬，泛化能力較強。
- **核函數 (`kernel`)**：
  - `linear`（線性核）：適用於高維且特徵數多的線性可分情境（如文字分類）。
  - `rbf`（高斯徑向基核）：最常用的強大非線性核函數。
  - `poly`（多項式核）：適用於多項式交互特徵。

### 樸素貝氏 (Naive Bayes)

**描述**：  
一種基於貝氏定理（Bayes' Theorem）並結合「特徵條件獨立性假設」的機率生成分類算法。它計算未知樣本在各類別下的後驗機率 $P(\text{類別} \mid \text{特徵})$，並選擇機率最高者作為預測類別。

![樸素貝氏分類原理：機率推斷與三大常見模型](images/04_naive_bayes.png)

**核心公式**：  
$$P(C \mid X) = \frac{P(C) \cdot P(X \mid C)}{P(X)}$$  
*(其中 $C$ 為類別，$X$ 為特徵向量；$P(C)$ 為先驗機率，$P(X \mid C)$ 為似然機率)*

**為什麼稱為「樸素 (Naive)」？**：  
它大膽假設：**在已知目標類別的條件下，所有輸入特徵之間彼此互相獨立、毫無關聯**。雖然這在現實世界中鮮少完全成立，但在實務上（特別是文本與高維特徵）卻能大幅簡化聯合機率的計算，並且常常取得令人驚艷的分類效果！

**三大常見模型類型**：
1. **高斯樸素貝氏 (GaussianNB)**：
   - 假設特徵數值服從常態高斯分佈。
   - 適用於連續型數值特徵（如身高、體重、溫度、血壓）。
2. **多項式樸素貝氏 (MultinomialNB)**：
   - 基於多項式分佈，專門處理離散的「計數」特徵。
   - 廣泛應用於自然語言處理（NLP）、詞袋模型（Bag-of-Words）、文本主題分類與垃圾郵件過濾。
3. **伯努利樸素貝氏 (BernoulliNB)**：
   - 基於多元伯努利分佈，專門處理二元布林值特徵（0 或 1）。
   - 僅關注某單詞或特徵「是否出現」，而不計次數。

**特點**：
- **訓練與預測極快**：只需統計各特徵的條件機率，推論速度極佳。
- **對少樣本非常友善**：在小規模數據集上表現相當穩定。
- **對缺失值具備良好容忍度**。
