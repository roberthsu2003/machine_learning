## 💡 為什麼採用「程式儲存格 ＋ AI 互動儲存格」的設計？

法務部同仁在學習新技術時，最常遇到兩大困擾：
1. 完全讓 AI 從無到有自由寫程式，常因模型隨機性、套件版號衝突或語法報錯，導致學習卡關挫折。
2. 傳統程式教材只有程式碼，沒有人解釋「為什麼公務上要這樣做」。

因此，本範例採用了最穩健的高品質學習架構：
1. **保證可執行的穩定基底**：我們已經在 [受刑人假釋再犯預測_分類篇.ipynb](./受刑人假釋再犯預測_分類篇.ipynb) 中為你依序寫好了標準的機器學習程式儲存格（經過完整測試，絕無語法報錯）。
2. **段段有解說**：每個程式儲存格的**正下方**，都緊接著一個專屬的文字儲存格，以法務實務白話詳細說明「這段程式在做什麼」。
3. **內建豐富的 AI 伴學對話小抄 (Prompt)**：每個步驟依據公務分析師應該掌握的核心觀念，提供多個不同角度的提問提示詞（包含公務指標解讀、統計陷阱防範、司法倫理探討與程式碼客製修改），你可以自由挑選並複製貼給 Copilot / ChatGPT！

## 📊 資料集介紹 (`recidivism.csv`)

📥 **資料集位置**：本機相對路徑 [`recidivism.csv`](./recidivism.csv)

本數據集記錄了法務部矯正署歷年審查之 2,000 筆受刑人假釋個案特徵與出獄後追蹤成效：

| 欄位名稱 | 數據型態 | 數值範例 / 類別 | 矯正公務與實務意涵 |
| :--- | :--- | :--- | :--- |
| **罪名類別** | 類別型 (`object`) | 毒品危害、詐欺洗錢、公共危險酒駕、竊盜侵占、暴力傷害 | 本次入監服刑之主要判決罪名 |
| **初次入監年齡** | 數值型 (`int64`) | 32 (歲，範圍 18~68 歲) | 衡量個案心理成熟度與涉入犯罪圈時長 |
| **入監前科次數** | 數值型 (`int64`) | 0~6 (次，0 代表初犯) | 歷史累犯紀錄，衡量再犯慣性之客觀指標 |
| **累進處遇級別** | 類別型 (`object`) | 一級(優良)、二級(良好)、三級(普通)、四級(初入) | 行刑累進處遇考核成績，反映在監教化成效 |
| **在監違規扣分次數** | 數值型 (`int64`) | 0~4 (次) | 服刑期間是否有違抗管教、違規記點紀錄 |
| **刑期已執行比例** | 數值型 (`float64`) | 0.75 (即已服滿 75% 刑期) | 比例愈高代表在監接受矯正時間愈充分 |
| **完成戒癮處遇** | 類別型 (`object`) | 是、否、無戒癮需求 | 是否如期完成毒品或酒癮戒治團體輔導 |
| **具家庭支持與固定居所** | 類別型 (`object`) | 是、否 | 出獄後是否有親友接納與落腳安居處所 |
| **兩年內是否再犯 (目標 y)** | 類別型 (`object`) | **「是」 / 「否」** | **預測目標變數（二元分類）** |

### 📋 複製給 AI 的專屬 Prompt

```text
請身為資深 Python 與機器學習工程師，為台灣法務部矯正署撰寫一個獨立完整的桌面 GUI 應用程式（單一 .py 檔案）。

【背景與數據說明】
1. 訓練資料集為 `recidivism.csv`，包含 2,000 筆受刑人假釋審查與追蹤數據。
2. 特徵欄位：
   - 數值型特徵：初次入監年齡（18~68 歲）、入監前科次數（0~6 次）、在監違規扣分次數（0~4 次）、刑期已執行比例（0.50~0.95）
   - 類別型特徵：罪名類別（毒品危害、詐欺洗錢、公共危險酒駕、竊盜侵占、暴力傷害）、累進處遇級別（一級(優良)、二級(良好)、三級(普通)、四級(初入)）、完成戒癮處遇（是、否、無戒癮需求）、具家庭支持與固定居所（是、否）
3. 目標預測變數：兩年內是否再犯（1 代表再犯，0 代表未再犯）

【功能與架構要求】
1. 機器學習管線 (ML Pipeline)：
   - 使用 Scikit-Learn 的 Pipeline 與 ColumnTransformer。
   - 數值特徵使用 StandardScaler 標準化，類別特徵使用 OneHotEncoder 編碼。
   - 採用隨機森林分類器 (RandomForestClassifier, n_estimators=100, max_depth=6, random_state=42) 作為預測模型。
   - 啟動程式時自動讀取 CSV 進行切分 (train_test_split 8:2) 並完成模型訓練，於介面頂端顯示模型評估指標（準確率 Accuracy、ROC-AUC）。
2. 圖形使用者介面 (GUI)：
   - 請優先使用 Python 內建的 Tkinter（包含 ttk 現代元件，公務電腦免安裝額外套件）。
   - 提供罪名、級別、戒癮、家庭支持的「下拉選單 (Combobox)」，以及前科次數、年齡、違規次數的「數值選單/滑桿」。
3. 解決「公務同仁手邊沒有測試資料」的關鍵功能：
   - 在介面上特別設計「快速預測測試範例 (Preset Scenarios)」區塊，提供 3 組具代表性的公務情境按鈕：
     * 情境 A：毒品累犯無家庭支持（典型高風險個案）
     * 情境 B：初犯優良在監刑期逾八成（典型低風險個案）
     * 情境 C：一般性情境觀察案
   - 同時提供一個「隨機情境按鈕」，隨機在合理範圍內產生個案特徵，點擊即帶入輸入框。
4. 預測結果顯示面板：
   - 點擊「立即評估受刑人再犯風險」按鈕後，以醒目色彩徽章顯示再犯風險等級（高風險/低風險）與預測機率百分比。
   - 提供「矯正署審查意見與保護管束建議」文字框，根據輸入特徵自動產出客製化建議（如加強毒品戒癮團督、聯絡更生保護會提供中途之家安置等）。
5. 程式碼品質：
   - 包含完整的繁體中文註解、良好的例外狀況處理（如檔案不存在或輸入異常時跳出友善提示對話框）。
```
