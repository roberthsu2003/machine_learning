# 範例 13 成果驗收與操作指引 (`RUN.md`)

## 1. 快速啟動說明

確保已經完成 `uv` 套件安裝與模型訓練後，在終端機中執行以下指令即可開啟桌面預測視窗：

```bash
cd 13_legal_contract_risk

# 啟動 Tkinter 桌面視窗應用
uv run python app.py
```

---

## 2. 測試驗收案例（Verification Cases）

開啟桌面視窗後，可測試以下三個極端與常規情境，驗證模型推論與法務建議邏輯：

### 測試案例 1：典型「高風險」採購合約（巨額、無賠償上限、境外管轄）
- **輸入條件**：
  - 合約類型：`採購合約`
  - 標的金額：`8,000,000` (800 萬)
  - 付款週期：`120 天`
  - 廠商設立年資：`1 年`（新公司）
  - 歷史爭議次數：`3 次`
  - 勾選：
    - [x] 無損害賠償責任上限
    - [x] 準據法為境外管轄
    - [x] 智慧財產權全數讓與對方
- **預期結果**：
  - 評估結果：🚨 **高風險合約 (High Risk)**
  - 建議文字：明確列出賠償上限缺失、境外訴訟成本、IP流失風險，並提示「建議退回重談」。

### 測試案例 2：標準常規「低風險」勞務或 NDA
- **輸入條件**：
  - 合約類型：`保密協議NDA`
  - 標的金額：`0`
  - 付款週期：`30 天`
  - 廠商設立年資：`15 年`（老牌廠商）
  - 歷史爭議次數：`0 次`
  - 勾選：
    - [ ] 無損害賠償責任上限（不勾選，即有設上限）
    - [ ] 境外管轄（不勾選，即本地管轄）
    - [ ] 自動續約（不勾選）
    - [ ] 智財權讓與（不勾選）
- **預期結果**：
  - 評估結果：✅ **低風險合約 (Low Risk)**
  - 建議文字：提示「本合約各項商業與法律條款合乎標準常規，可適用快速免審流程」。

## 3. 模型限制與法務倫理提示

1. **輔助決策，非取代法務**：
   - 機器學習模型提供的是「統計上的風險傾向預警」，不能取代合格法務人員或律師對具體事實情境之專業判斷。
2. **定型化契約外之特殊例外**：
   - 模型針對 10 項標準特徵進行推論，若合約中有未記錄在特徵表中的隱蔽條款（如特殊競業補償、保密違約定額罰金），仍需法務人工複核。
