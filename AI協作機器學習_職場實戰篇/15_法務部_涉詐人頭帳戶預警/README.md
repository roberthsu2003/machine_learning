## 📊 資料集介紹 (`fraud_accounts.csv`)

📥 **資料集位置**：本機相對路徑 [`fraud_accounts.csv`](./fraud_accounts.csv)

本數據集模擬法務部與高檢署打詐專案所整合之 3,000 筆金融帳戶動態特徵與檢察官偵結認定之人頭帳戶標籤：

| 欄位名稱 | 數據型態 | 數值範例 / 類別 | 司法檢察與洗錢防制實務意涵 |
| :--- | :--- | :--- | :--- |
| **開戶天數** | 數值型 (`int64`) | 45 (天，範圍 5~3650 天) | 新開戶未滿月或久未動用突然活化常為人頭戶特徵 |
| **開戶人年齡** | 數值型 (`int64`) | 23 (歲) | 年輕無經驗或急需資金族群常淪為被收購賣簿對象 |
| **是否有固定薪轉紀錄** | 類別型 (`object`) | 是、否 | 正常合法活絡帳戶多有規律雇主薪資入帳 |
| **近30天跨區與深夜ATM提款比率** | 數值型 (`float64`) | 0.85 (85%) | 洗錢車手為避人耳目常於深夜或跨縣市偏僻超商 ATM 密集提領 |
| **單日快進快出交易次數** | 數值型 (`int64`) | 12 (次) | 詐騙款項一旦匯入，數分鐘內即遭分批轉出或提領一空 |
| **單月入帳金額暴增倍數** | 數值型 (`float64`) | 15.5 (倍) | 平日餘額僅百元，突然單月湧入數百萬異常金流 |
| **是否開通網銀非約定轉帳** | 類別型 (`object`) | 是、否 | 開通非約定高額轉帳為詐騙洗錢分流至虛擬貨幣之關鍵跳板 |
| **聯徵中心信用異常註記** | 類別型 (`object`) | 是、否 | 包含信用卡強停、退票等信用瑕疵，易遭金錢誘惑賣簿 |
| **是否為涉詐人頭帳戶 (目標 y)** | 類別型 (`object`) | **「是」 / 「否」** | **預測目標：預警是否已淪為詐騙集團收購之洗錢人頭戶** |

### 📋 複製給 AI 的專屬 Prompt

```text
請身為資深 Python 與機器學習工程師，為台灣法務部打詐專案撰寫一個獨立完整的桌面 GUI 應用程式（單一 .py 檔案）。

【背景與數據說明】
1. 訓練資料集為 `fraud_accounts.csv`，包含 3,000 筆金融帳戶動態特徵與涉詐判定標籤。
2. 特徵欄位：
   - 數值型特徵：開戶天數（5~3,650 天）、開戶人年齡（18~72 歲）、近30天跨區與深夜ATM提款比率（0.0~1.0）、單日快進快出交易次數（0~25 次）、單月入帳金額暴增倍數（1.0~40.0 倍）
   - 類別型特徵：是否有固定薪轉紀錄（是、否）、是否開通網銀非約定轉帳（是、否）、聯徵中心信用異常註記（是、否）
3. 目標預測變數：是否為涉詐人頭帳戶（1 代表涉詐人頭戶，0 代表正常帳戶）

【功能與架構要求】
1. 機器學習管線 (ML Pipeline)：
   - 使用 Scikit-Learn 的 Pipeline 與 ColumnTransformer。
   - 數值特徵使用 StandardScaler 標準化，類別特徵使用 OneHotEncoder 編碼。
   - 採用隨機森林分類器 (RandomForestClassifier, n_estimators=100, max_depth=6, random_state=42) 作為預測模型。
   - 啟動程式時自動讀取 CSV 進行切分 (train_test_split 8:2) 並完成模型訓練，於介面頂端顯示模型評估指標（準確率 Accuracy、ROC-AUC）。
2. 圖形使用者介面 (GUI)：
   - 請優先使用 Python 內建的 Tkinter（包含 ttk 現代元件，公務電腦免安裝額外套件）。
   - 提供薪轉、非約定網銀、信用異常的「下拉選單 (Combobox)」，以及開戶天數、快進快出次數、暴增倍數、深夜提款比率的「滑桿/數值同步顯示」。
3. 解決「公務同仁手邊沒有測試資料」的關鍵功能：
   - 在介面上特別設計「快速預測測試範例 (Preset Scenarios)」區塊，提供 3 組具代表性的情資情境按鈕：
     * 情境 A：賣簿人頭戶（快進快出暴增20倍）
     * 情境 B：一般薪轉老戶（正常低風險）
     * 情境 C：疑似被吸收之學生帳戶（新開戶、深夜跨區提領多）
   - 同時提供一個「隨機情境按鈕」，隨機產生帳戶條件帶入輸入框。
4. 預測結果顯示面板：
   - 點擊「立即進行涉詐人頭帳戶風險預警研判」按鈕後，以醒目色彩徽章顯示判定等級（極高涉詐人頭戶風險 / 可疑異常 / 一般正常）與預測百分比。
   - 提供「檢警調與金融防詐聯防措施指引」文字框，根據輸入特徵自動產出客製化建議（如通報銀行圈存暫停非臨櫃交易、啟動洗錢防制法行政告誡、調閱來源 IP 等）。
5. 程式碼品質：
   - 包含完整的繁體中文註解、良好的例外狀況處理。
```
