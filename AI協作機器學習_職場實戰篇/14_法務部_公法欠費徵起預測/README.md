# 範例 14：法務部行政執行署—公法欠費案件「徵起可能性」預測與智慧分流 (分類篇)

本範例專為 **「法務部機關資料分析師（無機器學習背景）」** 設計，以公務行政中案量最龐大的 **「公法上金錢給付義務移送執行案件（欠稅、欠費、交通罰鍰）徵起率預測與案件智慧分流」** 為核心，帶領公務同仁體驗現代化的 **「AI 伴學模式」**。

## 📊 資料集介紹 (`execution_cases.csv`)

📥 **資料集位置**：本機相對路徑 [`execution_cases.csv`](./execution_cases.csv)

本數據集模擬法務部行政執行署各分署受理之 2,500 筆移送執行公法欠費個案特徵與最終徵起成果：

| 欄位名稱 | 數據型態 | 數值範例 / 類別 | 行政執行公務與實務意涵 |
| :--- | :--- | :--- | :--- |
| **案件類別** | 類別型 (`object`) | 綜合所得稅、地價房屋稅、交通酒駕罰鍰、健保勞保欠費、工商環保罰鍰 | 移送機關與案由法規性質 |
| **滯納欠款金額_TWD** | 數值型 (`int64`) | 120,000 (元，範圍 8,000~500 萬元) | 移送執行的本稅、本費與罰鍰累計總額 |
| **義務人性質** | 類別型 (`object`) | 個人自然人、營利事業法人 | 責任主體性質，影響名下財產調查途徑 |
| **義務人年齡** | 數值型 (`int64`) | 48 (歲) | 義務人年齡與勞動薪資能力密切相關 |
| **健保投保狀態** | 類別型 (`object`) | 固定受僱(有固定薪資)、職業工會(無固定薪資)、區公所投保(無業或弱勢) | 是否能直接核發「薪資扣押命令」之最大關鍵 |
| **名下財產車輛筆數** | 數值型 (`int64`) | 0~5 (筆，0 代表查無動產不動產) | 財政部財產清單查調之土地、房屋與車輛筆數 |
| **過往歷史完納率** | 數值型 (`float64`) | 0.0 ~ 1.0 (例如 0.8 代表過去移送曾完納 80%) | 義務人過往還款誠意與信用習慣指標 |
| **移送前催繳次數** | 數值型 (`int64`) | 1~5 (次) | 原處分機關在移送前發函催繳次數 |
| **是否成功徵起 (目標 y)** | 類別型 (`object`) | **「是」 / 「否」** | **預測目標：能否在執行程序中全額或部分徵起** |

## 🖥️ 進階專題：向 AI 索取「完整流程 ＋ 桌面 GUI 應用程式」

當你學會了筆記本中的特徵工程與模型預測觀念後，若想將機器學習模型打造成**獨立的桌面視窗軟體 (GUI)**（讓執行書記官與執行官在辦公室電腦隨點即開），可以直接複製以下這段設計好的 Prompt 貼給任何 AI（GitHub Copilot / ChatGPT / Claude）。

### 📋 複製給 AI 的專屬 Prompt

```text
請身為資深 Python 與機器學習工程師，為台灣法務部行政執行署撰寫一個獨立完整的桌面 GUI 應用程式（單一 .py 檔案）。

【背景與數據說明】
1. 訓練資料集為 `execution_cases.csv`，包含 2,500 筆公法欠費移送執行數據。
2. 特徵欄位：
   - 數值型特徵：滯納欠款金額_TWD（8,000~5,000,000 元）、義務人年齡（20~75 歲）、名下財產車輛筆數（0~5 筆）、過往歷史完納率（0.0~1.0）、移送前催繳次數（1~5 次）
   - 類別型特徵：案件類別（綜合所得稅、地價房屋稅、交通酒駕罰鍰、健保勞保欠費、工商環保罰鍰）、義務人性質（個人自然人、營利事業法人）、健保投保狀態（固定受僱(有固定薪資)、職業工會(無固定薪資)、區公所投保(無業或弱勢)）
3. 目標預測變數：是否成功徵起（1 代表成功徵起，0 代表未徵起）

【功能與架構要求】
1. 機器學習管線 (ML Pipeline)：
   - 使用 Scikit-Learn 的 Pipeline 與 ColumnTransformer。
   - 數值特徵使用 StandardScaler 標準化，類別特徵使用 OneHotEncoder 編碼。
   - 採用隨機森林分類器 (RandomForestClassifier, n_estimators=100, max_depth=6, random_state=42) 作為預測模型。
   - 啟動程式時自動讀取 CSV 進行切分 (train_test_split 8:2) 並完成模型訓練，於介面頂端顯示模型評估指標（準確率 Accuracy、ROC-AUC）。
2. 圖形使用者介面 (GUI)：
   - 請優先使用 Python 內建的 Tkinter（包含 ttk 現代元件，公務電腦免安裝額外套件）。
   - 提供案件類別、義務人性質、投保狀態的「下拉選單 (Combobox)」，以及金額輸入框與財產筆數、完納率的「滑桿/數值同步顯示」。
3. 解決「公務同仁手邊沒有測試資料」的關鍵功能：
   - 在介面上特別設計「快速預測測試範例 (Preset Scenarios)」區塊，提供 3 組具代表性的行政執行情境按鈕：
     * 情境 A：欠稅上班族（有固定薪資與房屋財產，高機率徵起）
     * 情境 B：酒駕拒繳慣犯（無業無財產，低機率徵起）
     * 情境 C：法人公司大額欠稅
   - 同時提供一個「隨機情境按鈕」，隨機產生案件條件帶入輸入框。
4. 預測結果顯示面板：
   - 點擊「立即進行公法欠費徵起可能性預測」按鈕後，以醒目色彩徽章顯示案件分流等級（高徵起成功率 / 中度可能性 / 難以徵起）與預測百分比。
   - 提供「行政執行處分建議方針（分流措施）」文字框，根據輸入特徵自動產出客製化建議（如批次核發薪資扣押命令、查封不動產、核發執行憑證或聲請拘提等）。
5. 程式碼品質：
   - 包含完整的繁體中文註解、良好的例外狀況處理。
```
