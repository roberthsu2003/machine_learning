## 📊 資料集介紹 (`execution_cases.csv`)

📥 **資料集位置**：本機相對路徑 [`execution_cases.csv`](./execution_cases.csv)

本數據集模擬法務部行政執行署各分署受理之 2,500 筆移送執行公法欠費個案特徵與最終徵起成果：

| 欄位名稱 | 數據型態 | 數值範例 / 類別 | 行政執行公務與實務意涵 |
| :--- | :--- | :--- | :--- |
| **案件類別** | 類別型 (`object`) | 綜合所得稅、地價房屋稅、交通酒駕罰鍰、健保勞保欠費、工商環保罰鍰 | 移送機關與案由法規性質 |
| **滯納欠款金額_TWD** | 數值型 (`int64`) | 120,000 (元，範圍 8,000~500 萬元) | 移送執行的本稅、本費與罰鍰累計總額 |
| **義務人性質** | 類別型 (`object`) | 個人自然人、營利事業法人 | 責任主體性質，影響名下財產調查途徑 |
| **義務人年齡** | 數值型 (`int64`) | 48 (歲) | 義務人年齡與勞動薪資能力密切相關 |
| **健保投保狀態** | 類別型 (`object`) | 固定受僱(有固定薪資)、職業工會(無固定薪資)、區公所投保(無業或弱勢) | 是否能直接核發「薪資扣押命令」之最大關鍵 |
| **名下財產車輛筆數** | 數值型 (`int64`) | 0~5 (筆，0 代表查無動產不動產) | 財政部財產清單查調之土地、房屋與車輛筆數 |
| **過往歷史完納率** | 數值型 (`float64`) | 0.0 ~ 1.0 (例如 0.8 代表過去移送曾完納 80%) | 義務人過往還款誠意與信用習慣指標 |
| **移送前催繳次數** | 數值型 (`int64`) | 1~5 (次) | 原處分機關在移送前發函催繳次數 |
| **是否成功徵起 (目標 y)** | 類別型 (`object`) | **「是」 / 「否」** | **預測目標：能否在執行程序中全額或部分徵起** |

## 🖥️ 進階專題：餵資料給 AI，打造獨立桌面分流 App (`app.py`)

在行政執行實務中，你不需要從頭手寫複雜的演算法代碼。當你掌握基本觀念後，你可以**直接把案件特徵與歷史徵起資料餵給 AI**，請 AI 為你建立公務電腦隨點即開的視窗分流工具 (`app.py`)。

但是，**新手千萬不要讓 AI 一口氣直接吐出程式碼**！因為 AI 常常會自作主張設定閾值、擅自處理缺失值，甚至選用黑盒子模型導致行政處分缺乏可解釋性。

因此，我們設計了這份**「優良的伴學諮詢式 Prompt」**：
- 它強制 AI 扮演**公務數據顧問**，嚴格禁止直接產出代碼！
- AI 必須逐項向你提問，且**每一次提問都必須以生活化白話向你解釋：「為什麼我必須這樣問你？這在行政執行與機器學習上有何代價？」**
- 透過人機協同決策，為執行署打造出最合身的案件分流系統！

### 📋 複製給 AI 的專屬【新手伴學諮詢 Prompt】

```text
你是一位專為「零程式背景、剛接觸機器學習的公務同仁/新手」服務的資深 AI 機器學習架構師與導師。

我現在手邊有一份資料集，我希望最終由你為我寫出一個單一、獨立、開箱即用的 Python 桌面視窗應用程式（`app.py`，使用 Python 內建的 Tkinter 或 PyQt）。

【我的公務資料說明】
資料檔案：`execution_cases.csv`（法務部行政執行署公法欠費移送執行紀錄）
資料欄位如下：
- 案件類別（綜合所得稅、地價房屋稅、交通酒駕罰鍰、健保勞保欠費、工商環保罰鍰）
- 滯納欠款金額_TWD（數值型，從數千元到數百萬元）
- 義務人性質（個人自然人、營利事業法人）
- 義務人年齡（數值型）
- 健保投保狀態（固定受僱(有固定薪資)、職業工會(無固定薪資)、區公所投保(無業或弱勢)）
- 名下財產車輛筆數（數值型）
- 過往歷史完納率（數值型，0.0~1.0）
- 移送前催繳次數（數值型）
- 是否成功徵起（是、否）

⚠️【極度重要規則：請絕對不要直接給我程式碼！】
因為我是機器學習新手，如果你直接給我整份程式碼，我無法理解背後的決策邏輯。
在動手寫程式碼之前，請你扮演「親切耐心的專業顧問」，依序向我確認關鍵問題。
並且，**你提出每一個問題時，都必須嚴格遵循以下「解說式提問格式」向我說明**：

--------------------------------------------------
【提問格式規範】
👉 問題 X：[你要問我的具體問題]
💡【為什麼我要這樣問你？（大白話解釋）】：[請用生活化白話向非工程師說明：為什麼演算法無法自己決定這件事？背後的資料科學原因是什麼？]
📌【建議選項與公務影響】：
   - 選項 A：...（說明若選此項，在公務實務或模型上的影響）
   - 選項 B：...（說明若選此項，在公務實務或模型上的影響）
--------------------------------------------------

請針對以下四個核心面向逐一向我提問，並附上白話解釋：

1. 【確認預測目標 Target / y】
   - 請告訴我：為什麼機器學習需要明確指定「哪一欄是結果標籤」，演算法才不會把欠稅金額當成目標？
2. 【極端金額與數值縮放的必要性】
   - 請告訴我：滯納金額從 5,000 元到 5,000,000 元相差千倍，為什麼必須做標準化 (StandardScaler)？如果不做會發生什麼數字霸凌現象？

4. 【桌面 App 的案件分流行動建議】

請立刻開始扮演顧問向我提問，等待我的回覆後，才進行 `app.py` 的程式碼撰寫！
```
