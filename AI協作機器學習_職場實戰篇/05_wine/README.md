# 05｜葡萄酒：單棵樹與森林

你提出需求、看懂結果並驗收；AI 負責寫程式、執行和除錯。

- **任務**：多類別分類（三種葡萄栽培品種來源）。
- **最小應用**：Streamlit 網頁應用。
- **專案 Prompt**：本資料夾內已備妥 [AGENT.md](./AGENT.md)，規範 AI 助教角色、繁體中文字型、決策樹超參數與防洩漏規則。
- **學生專案位置**：`05_wine/`（共用專案根目錄的 `.venv`）。
- **本例完成後**：可透過化學測量值分類葡萄品種，並說出一個模型限制。

---

## 資料與問題設定

[UCI Wine](https://archive.ics.uci.edu/dataset/109/wine)，178 筆、13 特徵、3 個葡萄栽培品種；CC BY 4.0。A1 由 AI 載入並儲存在本例 `data/`。（注意：本資料集為品種來源分類，非酒的好壞評分）。

- **X（特徵）**：13 個理化特徵（酒精濃度、蘋果酸、灰分、鎂、酚類、類黃酮、顏色濃度等）。
- **y（標籤）**：三類葡萄栽培品種來源（類別 0, 1, 2）。
- **切分規則**：以 `stratify=y`、`random_state=42` 切分 80/20；測試集嚴格封存至 A4 步驟；開發集共用相同 3 折分層 CV。
