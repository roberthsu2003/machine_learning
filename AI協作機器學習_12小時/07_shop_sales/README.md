# 07｜福利社：看見模型如何學出一條線

你提出需求、看懂結果並驗收；AI 負責寫程式、執行和除錯。

- **任務**：線性回歸與梯度下降參數優化。
- **最小應用**：Gradio 網頁應用。
- **專案 Prompt**：本資料夾內已備妥 [AGENT.md](./AGENT.md)，規範 AI 助教角色、繁體中文字型、訓練曲線繪製與防洩漏規則。
- **學生專案位置**：`07_shop_sales/`（共用專案根目錄的 `.venv`）。
- **本例完成後**：可依預估來客數推估營業額，並看懂學習率與訓練損失曲線。

## 資料與問題設定

本教材原創偽資料，`data/shop_sales.csv`，600 筆；固定 seed=7007。

### 範例檔下載
- [下載 shop_sales.csv](https://raw.githubusercontent.com/roberthsu2003/machine_learning/main/AI%E5%8D%94%E4%BD%9C%E6%A9%9F%E5%99%A8%E5%AD%B8%E7%BF%92_12%E5%B0%8F%E6%99%82/07_shop_sales/data/shop_sales.csv)：儲存至 `07_shop_sales/data/shop_sales.csv`。
- [線上資料卡](./data/DATA_CARD.md)：欄位定義與生成規則。

- **X（特徵）**：`visitors`（當日預估來客數，0～200）；排除 `day_id`、`is_synthetic`。
- **y（標籤）**：`sales_twd`（當日營業額，新台幣元）。
- **切分規則**：固定 `random_state=42` 隨機 80/20 切分，80% 開發集再切 75/25 為 train/val；測試集封存至 A4 步驟。

## A｜一步一步建立 Notebook（lesson.ipynb）

每次只貼一段 prompt，AI 執行後會提出一個觀念問題，確認理解後再貼下一段。

### A1｜讀取與觀察資料
> 觀念連結：[數據結構](../../名詞解釋/02_數據結構/README.md)

```text
請在 07_shop_sales/ 建立 lesson.ipynb，讀取 data/shop_sales.csv。
依 AGENT.md 確認 X／y，檢視資料形狀與數值摘要。
套用 AGENT.md 繁體中文字型設定，繪製來客數 vs 營業額散佈圖（全繁體中文標籤）。
說明線性關係中的「真實規律」與「隨機雜訊」，完成後請向我提出一個觀念思考題。
```

### A2｜切分與特徵縮放 Pipeline
> 觀念連結：[數據分割](../../名詞解釋/03_數據分割/README.md)、[特徵工程](../../名詞工程/04_特徵工程/README.md)

```text
依 AGENT.md 切分規則切分資料：
80/20 隨機切分封存 test 集；80% 開發集再切出 25% 作為驗證集（train/val）。
對 X 建立 StandardScaler。
說明為什麼使用梯度下降優化器（如 SGD）時，特徵縮放對收斂速度至關重要。
完成後請向我提出一個觀念思考題。
```

### A3｜梯度下降訓練過程與學習率實驗
> 觀念連結：[模型參數](../../名詞解釋/05_模型參數/README.md)、[優化算法](../../名詞解釋/06_優化算法/README.md)

```text
以 SGDRegressor 進行訓練：
1. 記錄每個 Epoch 的訓練集與驗證集損失（MSE Loss）。
2. 比較不同學習率（learning rate：過大如 1.0、過小如 0.0001、適中如 0.01）對收斂曲線的影響。
3. 繪製「迭代輪數 (Epoch) vs 損失曲線（Loss Curve）」（全繁體中文）。
4. 輸出模型最終學得的權重斜率（每增加 1 位客人多賺多少錢）與截距。
完成後請向我提出一個觀念思考題。
```

### A4｜評估與擬合線解讀
> 觀念連結：[評估指標](../../名詞解釋/09_評估指標/README.md)

```text
以最佳模型對封存的 test 集進行一次性最終評估。
計算 test MAE、RMSE 與 R²。
在散佈圖上疊加模型學出的迴歸直線，並標示出測試集樣本點。
挑出一個離直線最遠的測試點，說明「殘差（Residual）」的意義。
完成後請向我提出一個觀念思考題。
```

### A5｜保存與確認結果
```text
重啟 kernel 從頭重新執行 lesson.ipynb，確保圖表繁中與結果可復現。

另存 artifacts/metadata.json：記錄學習率、Epoch、最終權重/偏差、測試集指標。
以新 Python 程序載入模型驗證一組來客數輸入預測。
完成後回報成果。
```
