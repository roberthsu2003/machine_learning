# 07｜福利社：看見模型如何學出一條線

你提出需求、看懂結果並驗收；AI 負責寫程式、執行和除錯。此資料夾目前是提示詞教材，尚未有模型程式或 Notebook。

- 任務：回歸與優化。
- 最小應用：Gradio。
- 學生專案內位置：`07_shop_sales/`；共用專案根目錄的 `.venv`。
- 本例完成後：可用原始輸入執行預測，並說出一個模型限制。

## 資料與問題設定

本教材原創偽資料，data/shop_sales.csv，600 筆；固定 seed=7007，非真實福利社交易。

### 範例檔下載

- [下載 shop_sales.csv](https://raw.githubusercontent.com/roberthsu2003/machine_learning/main/AI%E5%8D%94%E4%BD%9C%E6%A9%9F%E5%99%A8%E5%AD%B8%E7%BF%92_12%E5%B0%8F%E6%99%82/07_shop_sales/data/shop_sales.csv)：只下載本例 CSV，儲存到學生專案的 `07_shop_sales/data/shop_sales.csv`。
- [線上閱讀偽資料卡與欄位字典](./data/DATA_CARD.md)：直接在 GitHub 閱讀，不必下載。

若連結顯示文字，使用瀏覽器「另存新檔」，保留 `.csv` 副檔名。使用這份固定 CSV，不請 AI 重新生成；本例不需要其他範例的資料，也不必下載整個 repo。

- **X（特徵）**：visitors（當日事前預估來客數，0～200），只用這一欄；day_id、is_synthetic 排除。
- **y（標籤）**：sales_twd（當日營業額）；這是加入雜訊的假想線性關係。
- **切分規則**：固定 random_state=42 隨機 80/20，80% 再切 75/25 為 train/val；本例是獨立模擬情境，day_id 不是時間，最終 20% test 只用一次。

## A｜一步一步建立 Notebook

先把本頁網址貼給 AI，再依序貼以下 prompt。
一次只貼一段，確認結果後再繼續；無法讀取網址時，貼上本頁內容。

### A0｜讓 AI 認識任務

```text
請閱讀我提供的教材與觀念連結，擔任我的機器學習助教。
沿用老師準備的環境，在 07_shop_sales/ 工作。
依本例設定逐步建立 lesson.ipynb，保留已完成內容。
用繁體中文說明，只做目前步驟；每步問我一個觀念問題。
能執行就直接執行；不能執行時明說，不編造成績。
現在先解釋問題、特徵與預期結果，不開始訓練。
```

### A1｜讀取與觀察資料

```text
在同一份 Notebook 載入本例資料。
讀取已下載的 data/shop_sales.csv，沿用固定偽資料。
依上方設定確認 X／y，顯示前五筆、欄位與缺值。
畫一張有用的圖，說明一列資料代表什麼。
缺檔時依上方下載連結取得，不換資料或重新生成。
```

### A2｜切分與前處理

```text
依上方「切分規則」分資料，不自行改成其他方式。
只用指定特徵，排除答案、ID 與生成提示欄位。
前處理只 fit train；交叉驗證時放在每折 Pipeline。
列出各份筆數，檢查重疊與洩漏，說明各自用途。
```

### A3｜訓練與比較模型

```text
以平均值與線性迴歸為基準，用 SGDRegressor 學直線。
X、y 各自只用 train 縮放，預測轉回台幣。
固定學習率，用 partial_fit 跑每個 epoch，最多 30 次。
學習率比較 0.0001、0.001、0.01，以 val MAE 選最佳模型。
比較只用 train／val 或開發集 CV，不用 test 挑設定。
執行後解釋比較結果；不要為了高分改資料。
```

### A4｜評估與解讀

```text
固定選好的模型與設定，再評估一次 test。
畫每個 epoch 的 train／val MAE 與學到的直線。
顯示一次 test MAE、RMSE、R²，解釋學習率的影響。
不要依 test 成績回頭調參；用生活語言說明結果。
```

### A5｜保存與確認結果

```text
重啟 kernel，從頭執行 lesson.ipynb，修正錯誤。
將完整前處理與模型保存到 artifacts/model.joblib。
另存 metadata.json：欄位、來源、切分、設定、指標與版本。
本例需要的門檻、scaler、圖表與範例也一起保存。
用新程序載入，比對同一輸入的預測，回報實際結果。
```
