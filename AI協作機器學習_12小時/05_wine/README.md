# 05｜葡萄酒：單棵樹與森林

你提出需求、看懂結果並驗收；AI 負責寫程式、執行和除錯。此資料夾目前是提示詞教材，尚未有模型程式或 Notebook。

- 任務：多類別分類。
- 最小應用：Streamlit。
- 學生專案內位置：`05_wine/`；共用專案根目錄的 `.venv`。
- 本例完成後：可用原始輸入執行預測，並說出一個模型限制。

## 資料與問題設定

[UCI Wine](https://archive.ics.uci.edu/dataset/109/wine)，178 筆、13 特徵、3 個葡萄栽培品種類別；CC BY 4.0。作者 S. Aeberhard、M. Forina，DOI：10.24432/C5PC7J。不是 Wine Quality 分數資料。

本例使用 scikit-learn 內附的開放資料，無需另外下載範例檔。A1 由 AI 載入並儲存在本例 `data/`，不需要下載整個 repo。

- **X（特徵）**：13 個化學測量欄位；target、索引不納入；單位依來源可確認者標示，未知單位不可自創。
- **y（標籤）**：三類葡萄栽培品種來源，不是酒的好壞或安全性。
- **切分規則**：stratified 80/20、random_state=42；開發資料 3 折分層 CV；所有模型共用相同折與固定 test。
