# 06｜批發客戶：沒有答案也能分群

你提出需求、看懂結果並驗收；AI 負責寫程式、執行和除錯。此資料夾目前是提示詞教材，尚未有模型程式或 Notebook。

- 任務：非監督式分群。
- 最小應用：Streamlit。
- 學生專案內位置：`06_wholesale/`；共用專案根目錄的 `.venv`。
- 本例完成後：可用原始消費欄位分派新客戶群組，並說出一個模型限制。

## 資料與問題設定

[UCI Wholesale Customers](https://archive.ics.uci.edu/dataset/292/wholesale+customers)，440 筆；CC BY 4.0。作者 M. Cardoso，DOI：10.24432/C5030X。

本例不另附資料檔。A1 由 AI 從上述 UCI 來源載入，只快取本例需要的資料到 `data/`；不需要下載整個 repo 或其他範例資料。

- **X（特徵）**：Fresh、Milk、Grocery、Frozen、Detergents_Paper、Delicassen 六欄年度消費；非負；來源未確定的金額單位不要自行寫成台幣。
- **y（標籤）**：沒有用來訓練的標籤；Channel／Region 不是「真實分群答案」，不得塞入 X 或計算分類 accuracy。
- **切分規則**：固定 random_state=42 留 20% 作未見客戶分派示範；只在 80% 開發集選 k。分群是探索分析，silhouette 不是監督式 test accuracy。

## A｜一步一步建立 Notebook

先把本頁網址貼給 AI，再依序貼以下 prompt。
一次只貼一段，確認結果後再繼續；無法讀取網址時，貼上本頁內容。

### A0｜讓 AI 認識任務

```text
請閱讀我提供的教材與觀念連結，擔任我的機器學習助教。
沿用老師準備的環境，在 06_wholesale/ 工作。
依本例設定逐步建立 lesson.ipynb，保留已完成內容。
用繁體中文說明，只做目前步驟；每步問我一個觀念問題。
能執行就直接執行；不能執行時明說，不編造成績。
現在先解釋問題、特徵與預期結果，不開始訓練。
```

### A1｜讀取與觀察資料

```text
在同一份 Notebook 載入本例資料。
用 ucimlrepo 的 fetch_ucirepo(id=292) 載入資料。
確認六個消費特徵，顯示前五筆、欄位與缺值；本例沒有 y。
畫一張有用的圖，說明一列資料代表什麼。
缺檔時依上方下載連結取得，不換資料或重新生成。
```

### A2｜切分與前處理

```text
依上方「切分規則」分資料，不自行改成其他方式。
只用指定特徵，排除答案、ID 與生成提示欄位。
前處理只 fit train；交叉驗證時放在每折 Pipeline。
列出各份筆數，檢查重疊與洩漏，說明各自用途。
```

### A3｜訓練與比較模型

```text
建立 log1p＋StandardScaler＋KMeans Pipeline。
只用開發集比較 k＝2、3、4，固定 n_init＝10。
依 silhouette 與群大小選 k；本例沒有分類答案。
比較只用 train／val 或開發集 CV，不用 test 挑設定。
執行後解釋比較結果；不要為了高分改資料。
```

### A4｜評估與解讀

```text
固定選好的分群模型，展示開發結果與未見客戶分派。
顯示 silhouette、群大小及原始消費中位數。
PCA 二維圖只作展示；未見客戶只預測群別。
不要依 test 成績回頭調參；用生活語言說明結果。
```

### A5｜保存與確認結果

```text
重啟 kernel，從頭執行 lesson.ipynb，修正錯誤。
將完整前處理與模型保存到 artifacts/model.joblib。
另存 metadata.json：欄位、來源、切分、設定、指標與版本。
本例需要的門檻、scaler、圖表與範例也一起保存。
用新程序載入，比對同一輸入的預測，回報實際結果。
```

## B｜把模型做成應用

完成 A5 後再貼 B1、B2。桌面版可使用[PyQt6 延伸 prompt](../README.md#想改成-pyqt6-桌面程式時)。

### B1｜建立介面

```text
讀取本例 Notebook 與 artifacts，用 Streamlit 建立 app.py。
輸入六個非負消費數值，顯示群別與群輪廓圖。
展示保存的分群比較，不把群別解釋成優劣。
載入已保存的完整模型，不在介面重新訓練。
以 app.py 的位置定位檔案，檢查輸入並標示來源與限制。
介面用繁體中文、僅供本機操作，提供啟動命令。
```

### B2｜驗收應用

```text
測試三組有效輸入，確認介面與 Notebook 預測一致。
檢查空白、非法輸入及缺少模型時的提示。
停止後重新啟動，確認仍能預測，修正實際發現的問題。
寫一份簡短 RUN.md，說明啟動、操作與模型限制。
回報已測試與待確認項目，再問我下方觀念問題。
```
