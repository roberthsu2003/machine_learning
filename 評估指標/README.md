# 評估指標 (Evaluation Metrics)

在機器學習中，評估指標是用來衡量模型性能的工具。不同的任務類型需要不同的評估方法。本講義將評估指標分為**分類任務**與**迴歸任務**兩大類，幫助您了解如何選擇與應用合適的評估方法。

---

## 評估指標概述

評估指標用於量化模型預測結果與實際結果之間的差異，幫助我們了解模型在區分不同類別、識別模式以及對新數據的泛化能力。特別是在類別分佈不均衡或特定錯誤代價較高的情況下，選擇正確的指標至關重要。

### 關鍵術語：混淆矩陣與基礎元素

在分類任務中，所有的評估指標基本上都源自於**混淆矩陣 (Confusion Matrix)**。混淆矩陣以表格形式展示了模型預測與真實標籤的對照關係：

|真實 \ 預測| 預測為正類 (Positive) | 預測為負類 (Negative) |
| :--- | :--- | :--- |
| **實際為正類 (Positive)** | **真正例 (True Positive, TP)**<br>模型正確預測為正類的樣本 | **假負例 (False Negative, FN)**<br>模型錯誤預測為負類的樣本（第一類錯誤） |
| **實際為負類 (Negative)** | **假正例 (False Positive, FP)**<br>模型錯誤地預測為正類的樣本（第二類錯誤） | **真負例 (True Negative, TN)**<br>模型正確預測為負類的樣本 |

> [!IMPORTANT]
> - **真正例 (TP)**：正確識別出的正類（例如：正確篩檢出癌症患者）。
> - **真負例 (TN)**：正確識別出健康者。
> - **假正例 (FP)**：錯誤判定為正類（例如：健康者被誤判為癌症，又稱**型一錯誤**）。
> - **假負例 (FN)**：錯誤判定為負類（例如：癌症患者漏診被判為健康，又稱**型二錯誤**）。

*   👉 [**混淆矩陣範例與視覺化程式碼**](./confusion_matrix.ipynb)

## 1️⃣ 分類任務評估指標 (Classification Metrics)

以下為常用的分類任務評估指標，點擊各指標標題可連結至對應的實作程式碼：

### 📈 [準確率 (Accuracy)](./accuracy.ipynb)
正確分類的樣本數佔總樣本數的比例。
*   **計算公式**：
    $$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}}$$
*   **最佳使用場景**：類別分佈均衡的數據集（例如垃圾郵件與非垃圾郵件數量相近）。
*   > [!WARNING]
    > **限制**：在不均衡數據集中可能具有高度誤導性（例如 95% 為負類，模型預測全為負類仍有 95% 準確率，但卻完全無法識別正類）。

### 🎯 [精確率 (Precision)](./precision.ipynb)
在所有預測為正類的樣本中，實際為正類的比例。
*   **計算公式**：
    $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$
*   **最佳使用場景**：**假正例 (FP)** 代價較高的場景。例如垃圾郵件過濾（不能把重要郵件誤判為垃圾郵件）或交易詐欺檢測。

### 🔍 [召回率 (Recall / Sensitivity)](./recall.ipynb)
在所有實際為正類的樣本中，被正確預測為正類的比例。
*   **計算公式**：
    $$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$
*   **最佳使用場景**：**假負例 (FN)** 代價較高的場景。例如癌症篩檢、傳染病診斷（不能漏診任何一個患者）。

### ⚖️ [F1 分數 (F1-Score)](./f1_score.ipynb)
精確率和召回率的調和平均數，提供平衡兩者的單一指標。
*   **計算公式**：
    $$\text{F1-score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$
*   **最佳使用場景**：當假正例和假負例都非常重要，且需要綜合權衡精確率與召回率時（例如資訊檢索、不平衡數據分類）。

### 📊 [AUC-ROC 曲線 (AUC-ROC Curve)](./auc_roc_curve.ipynb)
接收者操作特徵曲線 (ROC) 下的面積，用於評估二元分類器的整體性能。
*   **最佳使用場景**：衡量模型在不同分類閾值下區分正負類的能力，值越接近 1 代表性能越優異（例如信用風險評估）。

## 2️⃣ 迴歸任務評估指標 (Regression Metrics)

迴歸指標用於衡量模型預測連續數值與實際值之間的誤差大小與擬合程度。

### ➜ 資料變異性 (Data Variability) 與 R² 的關係

**資料變異性**是指數據點與平均值之間的差異程度（分散程度）。
例如，以下為兩組薪資數據的比較：

| 姓名 | 薪資組 A (低變異) | 薪資組 B (高變異) |
| :--- | :--- | :--- |
| 小明 | 30,000 | 30,000 |
| 小華 | 32,000 | 32,000 |
| 小美 | 31,000 | 31,000 |
| 小強 | **32,000** | **45,000** (離群值造成高變異) |

> [!NOTE]
> - **低變異性**：數據集中，點越靠近迴歸線 $\rightarrow$ $R^2$ 較高。
> - **高變異性**：數據分散 $\rightarrow$ $R^2$ 較低。如果 $R^2 = 0.95$，代表模型可以解釋 95% 的數據變化，僅有 5% 的變異無法被模型解釋。

---

以下為常用的迴歸評估指標，點擊各指標標題可連結至對應的實作程式碼：

### 📈 [R平方分數 (R² Score / Coefficient of Determination)](./r_squared.ipynb)
衡量模型解釋數據變異性的比例。
*   **數值意義**：
    *   $R^2 = 1$：完美預測，模型解釋了 100% 的變異。
    *   $R^2 = 0$：模型的預測與直接使用平均值無異。
    *   $R^2 < 0$：預測效果比直接取平均值還要差。
*   **最佳使用場景**：評估迴歸模型的整體擬合程度，判斷特徵（如年資）是否能良好解釋目標變數（如薪資）的變化。

### 📉 [均方誤差 (Mean Squared Error, MSE)](./mse.ipynb)
預測值與實際值之間差的平方的平均值。
*   **計算公式**：
    $$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$
*   **特點**：通過**平方**放大了較大誤差（懲罰離群值），結果越小代表模型越準確。
*   **限制**：單位是原始數據單位的平方（如：元²），不易直觀理解。

### 📏 [均方根誤差 (Root Mean Squared Error, RMSE)](./rmse.ipynb)
均方誤差的平方根。
*   **計算公式**：
    $$\text{RMSE} = \sqrt{\text{MSE}} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$
*   **特點**：開根號後**將單位轉回原始數據單位**（如：元），更容易直觀解釋平均誤差大小，同時保留對大誤差的懲罰特性。

### 📐 [平均絕對誤差 (Mean Absolute Error, MAE)](./mae.ipynb)
預測值與實際值之間絕對誤差的平均值。
*   **計算公式**：
    $$\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$
*   **特點**：使用絕對值計算，誤差單位與原始數據一致，結果直觀易懂。相較於 MSE/RMSE，它對極端異常值的敏感度較低（權重均勻）。
