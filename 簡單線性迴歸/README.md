## 📐 核心概念：理解線性迴歸公式 ($y = wx + b$)

線性迴歸的核心是透過一個簡單的線性方程式來建立輸入特徵與輸出預測之間的關係：

$$y = wx + b$$

- **$x$**：輸入特徵（自變數）
- **$y$**：預測結果（應變數）
- **$w$ (Weight)**：權重，代表直線的**斜率 (Slope)**，決定直線的傾斜程度。
- **$b$ (Bias)**：偏差，代表直線的**截距 (Intercept)**，決定直線在 y 軸上的起點。

### 學習目標
1. **數值生成**：了解如何給定一組 $x$ 值，透過公式 $y = wx + b$ 計算出對應的 $y$ 值。
2. **幾何意義**：理解在二維空間中，將這些 $(x, y)$ 點連接起來會形成一條直線。

### 2. 損失函數與成本函數 (Cost Function)
為了衡量預測值與真實值之間的落差，我們使用**均方誤差 (MSE)** 作為成本函數：
$$\text{Cost} = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$
透過計算所有資料點「預測值」與「真實值」的平方差平均，我們可以得到一個用來代表預測誤差的數值。

- **當固定 $b=0$，調整 $w$** 時，斜率與誤差呈二次曲線關係：

在實際專案中，我們通常直接調用成熟的機器學習套件如 **scikit-learn**，以提高開發效率。

### 1. 線性迴歸與普通最小平方法 (OLS)
在 scikit-learn 中，`LinearRegression` 類別使用的是**普通最小平方法 (Ordinary Least Squares, OLS)**。
- **基本原理**：此方法同樣是以最小化均方誤差為目標來求解參數 $w$ 與 $b$。
- **公式延伸（多特徵情況）**：
  若資料集有多個特徵（例如預測房價時，有面積、房間數、地段等多個自變數），預測公式會擴展為：
  $$\hat{y} = w_0 x_0 + w_1 x_1 + \dots + w_p x_p + b$$
  其中 $p$ 為特徵個數。
