## 🚀 實作情境：我不知道要問 AI 什麼，該怎麼開始？

### 步驟 1：在 Jupyter Notebook 中檢視資料
建立並開啟你的 Jupyter Notebook（例如 `my_practice.ipynb`），輸入並執行以下 6 行代碼：

```python
import pandas as pd

df = pd.read_csv("data/advSale.csv")
print("=== 資料筆數與型態 ===")
print(df.info())
print("\n=== 前 3 筆資料樣本 ===")
print(df.head(3))
```

執行後，將終端機印出的輸出結果複製起來。

## 💡 AI 回覆後，學生該怎麼做？

1. **閱讀 AI 的白話解說**：AI 會告訴你這是「預測數值的連續迴歸任務」，目標是透過電視、廣播、社群與網紅廣告來預測「銷售額」。
2. **複製 AI 給的第一步代碼**：將代碼貼入 Notebook 執行（通常是計算相關係數與畫圖）。
3. **回答 AI 的引導問題**：看著圖表或輸出，用自己的話回答 AI 提問的思考題（例如：「電視廣告看起來跟銷售額最相關！」）。
4. **說「請帶我進入下一步」**：AI 就會一步一步引導你完成特徵前處理、Pipeline 建模、解讀 R² 分數，直到最後完成預測！
