## 🚀 實作流程：在 Notebook 儲存格中與 AI 對話

### 步驟 1：在你的 Notebook 第一個儲存格載入資料
在你的 Jupyter Notebook（例如 `my_practice.ipynb`）的第一個 Code 儲存格中輸入並執行：

```python
import pandas as pd

df = pd.read_csv("data/advSale.csv")
print("=== 資料筆數與型態 ===")
print(df.info())
print("\n=== 前 3 筆資料樣本 ===")
print(df.head(3))
```

執行後，你會在儲存格下方看到印出的資料結構與前 3 筆數據。
