## 💡 為什麼採用「程式儲存格 ＋ AI 互動儲存格」的設計？

過去如果完全讓外部 AI 從無到有自由生成程式碼，常因各家 AI 表現不一（有些模型一次全寫完、有些遺漏資料切分、有些套件版本不合）而導致學習體驗非常不穩定。

因此，本範例採用了最穩健、高品質的學習架構：
1. **保證可執行的穩定基底**：我們已經在 [廣告效益預測_迴歸篇.ipynb](./廣告效益預測_迴歸篇.ipynb) 中為你依序寫好了標準的機器學習程式儲存格（經過完整測試，絕無語法報錯）。
2. **段段有解說**：每個程式儲存格的**正下方**，都緊接著一個專屬的文字儲存格，詳細說明「這段程式在做什麼」。
3. **內建豐富的 AI 伴學對話小抄 (Prompt)**：每個文字儲存格依據該步驟學生應該掌握的核心觀念，提供多維度的提問提示詞（包含觀念深入拆解、統計陷阱防範、商業決策解讀與程式碼客製修改），你可以自由挑選並複製貼給 AI！

> 💡 **特別設計**：很多同學手邊沒有「未來的預測資料集」，因此這個 Prompt 特別要求 AI 在介面中**內建實務預測情境範例按鈕**與**隨機生成合理測試資料**功能，讓你不需額外找資料就能立刻進行預測互動！

### 📋 複製給 AI 的專屬 Prompt

```text
請身為資深 Python 與機器學習工程師，為我撰寫一個獨立完整的桌面 GUI 應用程式（單一 .py 檔案）。

【背景與數據說明】
1. 訓練資料集為 `advSale.csv`，包含 4,500 筆廣告投入與銷售額數據。
2. 特徵欄位：

   - 數值型特徵：電視廣告（10~100 千元）、廣播廣告（0~50 千元）、社群媒體廣告（0~15 千元）
   - 類別型特徵：網紅廣告（四個級距：「大於百萬」、「十萬到百萬」、「一萬到十萬」、「小於一萬」）
3. 目標預測變數：銷售額（連續數值，單位：萬元）

【功能與架構要求】
1. 機器學習管線 (ML Pipeline)：
   - 使用 Scikit-Learn 的 Pipeline 與 ColumnTransformer。
   - 數值特徵使用 StandardScaler 標準化，類別特徵使用 OneHotEncoder 編碼。
   - 採用線性迴歸 (LinearRegression) 作為預測模型。
   - 啟動程式時自動讀取 CSV 進行切分 (train_test_split 8:2) 並完成模型訓練，於介面頂端顯示模型評估指標（R²、MAE、RMSE）。
2. 圖形使用者介面 (GUI)：
   - 請優先使用 Python 內建的 Tkinter（包含 ttk 現代元件，使用者免安裝額外套件）。
   - 提供電視、廣播、社群廣告的「滑桿 + 數值輸入框」雙向同步控制，以及網紅等級的「下拉選單 (Combobox)」。
3. 解決「使用者手邊沒有預測資料」的關鍵功能：
   - 在介面上特別設計「快速預測測試範例 (Preset Scenarios)」區塊，提供 3 組實務投放情境按鈕（例如：情境 A 電視主打、情境 B 平衡推廣、情境 C 社群新創）一鍵帶入參數。
   - 同時提供一個「隨機情境按鈕」，隨機在合理數值範圍內產生測試資料，點擊即帶入輸入框。
4. 預測結果顯示面板：
   - 點擊「計算預期產品銷售額」按鈕後，以醒目大字體顯示預估銷售額（萬元）。
   - 提供詳細報告文字框，顯示總預算投入合計（萬元）、預期銷售額以及投報比例 (ROI) 商業決策建議。
5. 程式碼品質：
   - 包含完整的繁體中文註解、良好的例外狀況處理（如檔案不存在或輸入異常時跳出友善提示對話框）。
```
