## 📊 資料集概要 (`advSale.csv`)

資料集記錄了 4,500 筆在不同媒體渠道投放廣告的費用與最終達成的產品銷售額：

| 欄位名稱 | 數據型態 | 說明 | 範例數值 |
| :--- | :--- | :--- | :--- |
| **電視廣告** | 數值型 (float) | 電視廣告投入預算（單位：千元） | 93.0 |
| **廣播廣告** | 數值型 (float) | 廣播電台廣告投入預算（單位：千元） | 25.64 |
| **社群媒體廣告** | 數值型 (float) | 網路社群平台投放廣告預算（單位：千元） | 5.12 |
| **網紅廣告** | 類別型 (string) | 合作網紅的粉絲規模級距 | `大於百萬`、`十萬到百萬`、`一萬到十萬`、`小於一萬` |
| **銷售額 (目標 y)** | 數值型 (float) | 該期產品最終銷售總額（連續目標） | 334.54 |

## 🎯 學習目標

1. **學會資料餵入格式**：掌握如何將多欄位、混合型態（數值＋類別）的資料摘要餵給 AI。
2. **理解迴歸問題**：當預測目標是連續數值（如銷售額、房價、氣溫）時，該如何請 AI 推薦合適的模型。
3. **掌握特徵工程提問技巧**：引導 AI 正確處理類別型特徵（One-Hot Encoding）與數值縮放（StandardScaler），並封裝於 Pipeline 中避免資料洩漏。
4. **指標解讀能力**：不依賴 AI 敷衍的一句話，而是學會追問 MAE（平均絕對誤差）、RMSE（均方根誤差）與 R²（判定係數）的商業意涵。
5. **情境推論試算**：引導 AI 建立預測函式，直接代入公司下季度的廣告預算組合，計算出預期銷售額與各媒體的投資效益。
