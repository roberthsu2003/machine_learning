## 🧭 機器學習流程通關地圖：AI 提問時你該注意什麼？如何胸有成竹地回答？

初學者最常遇到的困擾是：「AI 在下方儲存格向我提問時，我不知道它的背後目的，也不知道該怎麼回答。」  
其實整個機器學習有固定的五大標準流程。請把以下表格當作你的**「通關小抄」**，當 AI 提問時，只要對照當前階段的核心觀念，就能輕鬆掌握節奏、精準回應 AI：

| 流程階段 | 學生該注意的核心重點 (What to Watch) | AI 常問你的思考題範例 | 學生建議的回答方向 (How to Respond) |
| :--- | :--- | :--- | :--- |
| **第 1 關：資料探索 (EDA)** | - 找出誰對預測目標影響最大（看**相關係數**）。<br>- 注意是否有文字欄位（網紅廣告）。 | 「你看這張熱力圖/散佈圖，哪一種廣告對銷售額影響最大？文字欄位該怎麼辦？」 | **「電視廣告相關係數高達 0.99，是主要驅動力；廣播也有輔助效果。網紅廣告是中文字串，後續需要轉為數字。」** |
| **第 2 關：特徵工程與防洩漏切分** | - **絕對不可偷看測試集！** 必須先切分 80% 訓練、20% 測試。<br>- 類別要轉數字 (One-Hot)，數值要標準化 (Scaler)，且必須包進 **Pipeline**。 | 「為什麼不能在切分測試集前對整份資料做標準化？訓練集要抓幾成？」 | **「先做標準化會把測試集的統計量洩漏進去（Data Leakage）；建議切 80% 訓練、20% 測試，並用 Pipeline 包起來防止作弊。」** |
| **第 3 關：模型選型與比較** | - 迴歸問題要選迴歸演算法。<br>- 先建立簡單的**基準模型 (多元線性迴歸)**，再比對**進階模型 (隨機森林)**。<br>- 用 5 折交叉驗證 (CV) 檢驗穩定度。 | 「這既然是連續數值預測，你想先用什麼簡單模型當 Baseline？要跟哪種進階模型比較？」 | **「我想用『多元線性迴歸』當基準模型，並和『隨機森林迴歸』進行比較，請幫我用 5 折交叉驗證看穩定度！」** |
| **第 4 關：測試集大考與指標解讀** | - **迴歸不能看準確率 (Accuracy)！**<br>- 看 **R²（判定係數，越接近 1 越好）** 與 **RMSE / MAE（誤差多少金額，越小越好）**。 | 「測試集評估出來了，多元線性迴歸的 R² 是 0.998、RMSE 是 2.98，你覺得表現如何？選哪一個？」 | **「R² 接近 1 代表能解釋近 100% 的銷售變異，RMSE 誤差很小，模型非常成功！由於線性迴歸又快又好解釋，建議選擇多元線性迴歸。」** |
| **第 5 關：情境試算與商業決策** | - 模型是拿來決策的！<br>- 輸入未來的廣告配置預算，讓模型即時預估銷售額。 | 「模型訓練完了，你想輸入什麼樣的廣告預算組合來做試算？」 | **「我想比較『方案 A (加碼電視)』與『方案 B (加碼社群)』，請建立一個預測函式，直接幫我算預估銷售額！」** |
