# 💬 範例 01：向 AI 提問的五階段實戰手冊 (迴歸篇)

本手冊為初學者量身打造。當你面對 `data/advSale.csv` 這份廣告銷售數據時，請依照以下五個階段，將各階段的提示詞複製給你的 AI 工具（例如 ChatGPT, Claude 或 IDE 內的 AI 助理）。

---

## 📌 提問心法：初學者常見的三大錯誤

1. ❌ **錯誤一：直接叫 AI 寫程式**
   - *反面範本*：「請幫我對這份廣告資料做機器學習。」
   - *結果*：AI 會隨便假設欄位、一次性噴出 100 行沒註解的代碼，如果報錯你完全不知道發生了什麼。
2. ❌ **錯誤二：把整個 CSV 貼進去**
   - *反面範本*：複製 4500 行貼進對話視窗。
   - *結果*：超出 token 上限、AI 記憶錯亂。
3. ✅ **正確做法：先給資料概況，分階段推進**
   - 階段 0：設定角色 ＋ 給予資料 Metadata
   - 階段 1：探索與視覺化 (EDA)
   - 階段 2：資料前處理與切分
   - 階段 3：模型選型與訓練 (Pipeline)
   - 階段 4：指標白話解讀與評估
   - 階段 5：情境預測實測

---

## 🚀 階段 0：角色設定與資料餵入

### 步驟 0-1：在 Python 中取得資料摘要
在 Jupyter Notebook 中執行以下簡短代碼，將輸出結果複製起來：
```python
import pandas as pd
df = pd.read_csv("data/advSale.csv")
print("=== 資料筆數與型態 ===")
print(df.info())
print("\n=== 前 3 筆資料樣本 ===")
print(df.head(3))
```

### 步驟 0-2：複製以下 Prompt 給 AI 🚀
> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 你現在是一位專業且擅長教學的「機器學習專案導師」。我是一位剛接觸機器學習的初學者，我想利用手上的一份行銷廣告數據來進行機器學習實作。
> 
> 以下是我手上的資料摘要：
> 1. 資料總筆數：4,500 筆，欄位共有 5 個，沒有缺失值。
> 2. 欄位明細：
>    - 電視廣告 (float64)：電視廣告投放費用
>    - 廣播廣告 (float64)：廣播廣告投放費用
>    - 社群媒體廣告 (float64)：社群媒體廣告投放費用
>    - 網紅廣告 (object)：合作網紅規模，值包含「大於百萬」、「十萬到百萬」、「一萬到十萬」、「小於一萬」
>    - 銷售額 (float64)：產品最終銷售額
> 3. 前 3 筆樣本：
>       電視廣告       廣播廣告    社群媒體廣告   網紅廣告         銷售額
>    0  93.0  25.647047  5.124376  一萬到十萬  334.542585
>    1  79.0  28.862860  1.487848   小於一萬  283.111546
>    2  30.0   4.328536  0.477257  一萬到十萬  102.350794
> 
> 我的目標：預測「銷售額」。
> 
> 【互動規範】：
> 1. 請全程使用台灣繁體中文專業術語回答我。
> 2. 請先回答我：這屬於機器學習中的哪一種任務（分類、迴歸還是分群）？為什麼？
> 3. 請不要一口氣寫完全部專案程式，請只列出我們接下來要進行的步驟清單，並詢問我是否準備好開始第一步。
> ```

## 🔍 階段 1：資料探索 (EDA) 與關聯性提問

當 AI 回覆你這是「連續數值迴歸 (Regression)」任務後，進入第一步：了解特徵之間的關係。

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 我想先看懂這份資料。請提供一段 Python 探索性資料分析 (EDA) 的程式碼，並滿足以下要求：
> 1. 計算各數值特徵與「銷售額」的皮爾森相關係數 (Correlation)，並排出對銷售額影響力最大的前兩大管道。
> 2. 使用 Matplotlib / Seaborn 繪製一張散佈圖矩陣 (Pairplot) 或熱力圖 (Heatmap)。
>    - 必須注意：圖表支援中文字型顯示（可以使用 `mplfonts` 或系統中文字型），避免方塊亂碼。
> 3. 執行後請告訴我：身為一個初學者，我該如何解讀這張圖？
> ```

### 🎓 學生學習檢核點：
- 電視廣告是否與銷售額有高度正相關？（通常係數大於 0.8 表示高度相關）
- 廣播廣告與社群廣告是否有輔助效果？

## 🛠️ 階段 2：資料前處理與特徵工程提問

這份資料包含了「類別型欄位（網紅廣告）」與「數值型欄位」，初學者常常不知道怎麼轉換成演算法看得懂的數字。

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 我發現「網紅廣告」欄位是中文字串（如：大於百萬、一萬到十萬），而其他是數值。
> 
> 請教導我並提供標準 Scikit-Learn 處理程式碼：
> 1. 如何將特徵 X 與目標 y 分離？
> 2. 如何切分訓練集 (Train Set) 與測試集 (Test Set)？比例建議多少？為什麼隨機種子 (random_state) 一定要固定？
> 3. 針對數值欄位做標準化 (StandardScaler)，針對網紅廣告做獨熱編碼 (One-Hot Encoding)。
>    - 請務必使用 `ColumnTransformer` 進行整合。
>    - 請告訴我：為什麼這些前處理不能在「切分測試集之前」就對全部資料做？（請用白話解釋什麼叫 Data Leakage 資料洩漏）
> ```

## 🤖 階段 3：模型選型與比較提問

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 請幫我建立兩個迴歸模型進行比較：
> 1. 基準模型 (Baseline)：多元線性迴歸 (LinearRegression)
> 2. 進階模型：隨機森林迴歸 (RandomForestRegressor)
> 
> 請遵循最佳工程實踐：
> - 將上一階段的 `ColumnTransformer` 和模型用 `sklearn.pipeline.Pipeline` 打包在一起。
> - 僅在訓練集 (X_train, y_train) 上呼叫 `.fit()`。
> - 執行 5 折交叉驗證 (5-Fold Cross Validation) 檢驗模型穩定度。
> - 請先不要在測試集上做評估，先告訴我這兩個模型的交叉驗證得分。
> ```

## 📈 階段 4：測試集評估與指標白話解讀

訓練完成後，我們才拿出神聖不可侵犯的「測試集」做最終大考！

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 現在我們要用測試集 (X_test, y_test) 來評估這兩個模型的泛化能力。
> 
> 請提供評估程式碼，並計算出以下指標：
> 1. MAE (平均絕對誤差)
> 2. RMSE (均方根誤差)
> 3. R² (判定係數)
> 
> 【重點解說要求】：
> 請不要只輸出數字，請用國中生都能聽懂的白話方式，回答我：
> - 什麼是 R² 分數？如果 R² = 0.98 代表什麼商業意義？
> - MAE 和 RMSE 有什麼不同？如果兩者差距很大代表資料中有什麼情況？
> - 哪一個模型表現更好？我們最終該選擇哪一個？
> ```

## 💡 階段 5：實務情境推論試算 (Inference)

機器學習最終是要解決商業問題。如何利用訓練好的模型來做預算決策？

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 模型已經訓練好了！我們行銷部下個季度打算評估以下兩種廣告投放方案：
> - 【方案 A】：電視廣告投入 80 千元、廣播投入 30 千元、社群投入 5 千元、網紅找「大於百萬」粉絲。
> - 【方案 B】：電視廣告投入 50 千元、廣播投入 10 千元、社群投入 2 千元、網紅找「小於一萬」粉絲。
> 
> 請寫出一個 Python 函式 `predict_sales(model, input_dict)`：
> 1. 輸入上述方案的字典資料，自動轉為 DataFrame 並透過 Pipeline 預測出預估銷售額。
> 2. 比較方案 A 與方案 B 的預估銷售額，並根據模型各特徵的權重/重要性，給行銷長一句話的預算配置建議。
> ```

## 🛡️ 初學者防雷檢查清單 (AI Code Review Checklist)

當 AI 給出程式碼時，請用以下 4 點檢查 AI 有沒有偷懶或犯錯：

- [ ] **是否先切分 Train/Test，才做 Preprocessing？**（若 AI 在切分前就對整份 DataFrame 做 `get_dummies` 或 `StandardScaler`，請叫它重寫成 Pipeline）。
- [ ] **是否有固定 `random_state=42`？**（避免每次執行結果不同）。
- [ ] **中文字型是否正確處理？**（若圖表中文出現方塊亂碼 `□□`，請提示 AI 套用 `mplfonts.use_font('Noto Sans CJK SC')`）。
- [ ] **Pipeline 是否直接接受原始特徵 DataFrame？**（在預測新資料時，不需要手動先做 One-Hot 編碼，Pipeline 會自動處理）。
