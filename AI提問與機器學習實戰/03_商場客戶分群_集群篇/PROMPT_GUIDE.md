# 💬 範例 03：向 AI 提問的五階段實戰手冊 (集群篇)

本手冊帶領初學者掌握「非監督式學習 (Unsupervised Learning)」的提問精髓。當你手上有一份顧客資料卻沒有任何標籤時，請依照以下五個階段，逐步將提示詞複製給你的 AI 工具。

---

## 📌 提問心法：初學者在非監督學習常踩的雷

1. ❌ **誤以為一定要切 Train / Test**
   - 初學者問 AI：「請幫我把資料切成 80% 訓練集和 20% 測試集來做分群。」
   - *觀念矯正*：純探索性分群是為了解讀當前資料庫的群體結構，不需要切分測試集（除非是用於半監督式或生產環境的推論管線）。
2. ❌ **忽略特徵尺度 (Scaling)**
   - K-Means 是基於「幾何歐氏距離」分組。如果不做標準化，數值範圍大的欄位（如年收入 100）會完全壓制數值範圍小的欄位（如年齡 20）。
3. ❌ **隨便拍腦袋決定群數 K**
   - 必須透過「手肘法」或「輪廓係數」等客觀指標，請 AI 輔助找出最合理的群數。

---

## 🚀 階段 0：角色設定與資料餵入

### 步驟 0-1：在 Python 中取得資料摘要
在 Jupyter Notebook 中執行：
```python
import pandas as pd
df = pd.read_csv("data/customer.csv")
print("=== 資料筆數與統計量 ===")
print(df.info())
print("\n=== 前 3 筆樣本 ===")
print(df.head(3))
```

### 步驟 0-2：複製以下 Prompt 給 AI 🚀
> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 你現在是一位專業的「商務數據分析與機器學習導師」。我是一位初學者，手上有一份百貨商場的顧客消費數據 `data/customer.csv`。
> 
> 以下是資料集摘要：
> 1. 總筆數：200 筆，沒有缺失值。
> 2. 欄位明細：
>    - `性別` (object): 男 / 女
>    - `年齡` (int64): 範圍 18 ~ 70 歲
>    - `收入(千)` (int64): 範圍 15 ~ 137 千元
>    - `消費指數(1-100)` (int64): 範圍 1 ~ 99 分，分數越高代表消費頻率與花費越高
> 3. 前 3 筆樣本：
>      性別  年齡  收入(千)  消費指數(1-100)
>   0  男    34     78            1
>   1  男    20     61           49
>   2  男    29     28           82
> 
> 我的目標：這份資料**沒有任何標籤 y**，我希望進行「客戶分群 (Customer Segmentation)」，找出不同的消費行為群體，以利行銷部門進行精準行銷。
> 
> 【互動規範】：
> 1. 請全程使用台灣繁體中文專業術語回答我。
> 2. 請先回答我：這屬於機器學習中的哪一種任務（監督式還是非監督式）？常用演算法是什麼？
> 3. 請不要直接給我完整程式碼，請列出後續五個分析步驟，等我確認後再進行下一步。
> ```

## 🔍 階段 1：資料探索與尺度差異提問

當 AI 回覆這是「非監督式集群 (Clustering)」任務並建議使用 K-Means 時，我們進入第一步。

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 我們決定先聚焦在「收入(千)」與「消費指數(1-100)」這兩個核心特徵進行分群探索。
> 
> 請提供一段 Python 探索與視覺化程式碼：
> 1. 繪製以「收入(千)」為 X 軸、「消費指數(1-100)」為 Y 軸的散佈圖 (Scatter plot)。
> 2. 請支援繁體中文字型顯示（使用 `mplfonts` 或系統字型避免方塊亂碼）。
> 3. 請用通俗語言回答我：從未分群的散佈圖中，肉眼看起來大約自然形成了幾個群體？
> 4. 在執行 K-Means 之前，為什麼「特徵標準化 (StandardScaler)」在距離演算法中如此重要？
> ```

---

## 🛠️ 階段 2：客觀決定最佳群數 K (手肘法與輪廓分析)

初學者最常問的問題就是：「我怎麼知道該分成 3 群、4 群還是 5 群？」

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 我想客觀決定最佳分群數 K。
> 
> 請提供 Python 程式碼，測試 K=2 到 K=9：
> 1. 先使用 `StandardScaler` 對「收入(千)」與「消費指數(1-100)」進行標準化。
> 2. 計算每個 K 的「組內平方和 (Inertia / WCSS)」，並繪製「手肘法折線圖 (Elbow Method)」。
> 3. 計算每個 K 的「輪廓係數 (Silhouette Score)」，並繪製對應折線圖。
> 
> 【指標白話解說】：
> 請向我這個初學者解釋：
> - 什麼叫「手肘點 (Elbow Point)」？圖形轉折處代表什麼幾何意義？
> - 輪廓係數 (Silhouette Score) 的數值範圍是多少？分數越高代表什麼？
> - 綜合這兩張圖，你推薦我們將顧客分成幾個群體最合理？
> ```

## 🤖 階段 3：執行 K-Means 演算法與視覺化

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 根據手肘法與輪廓係數，我們決定設定 K=5。
> 
> 請提供 Python 程式碼：
> 1. 使用 `sklearn.cluster.KMeans(n_clusters=5, random_state=42)` 進行分群。
> 2. 將分群標籤（0 到 4）存回原始 DataFrame 的新增欄位 `群別`。
> 3. 繪製精美的 5 群彩色散佈圖，並用明顯的紅色大叉叉標示出各群的「質心 (Centroids)」座標。
> 4. 請將質心座標逆轉換 (inverse_transform) 回原始數值（收入與消費指數），方便我們直接理解。
> ```

## 📊 階段 4：客群畫像命名與商業行銷解讀

分群不是畫完圖就結束，資料科學家的價值在於「將數學群體轉化為商業語言」。

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 現在 5 個群體已經分好。請提供一段 Python 程式碼，以 `groupby('群別')` 計算這 5 個群體在「年齡」、「收入(千)」、「消費指數(1-100)」的平均值與人數。
> 
> 【商業畫像解說要求】：
> 請扮演行銷總監，為這 5 個客群分別取一個生動具體的商業暱稱（例如：「高收奢華族」、「謹慎小資族」等），並為每一個客群提出 1~2 點具體的行銷活動策略建議！
> ```

## 💡 階段 5：新顧客即時歸類與推論應用 (Inference)

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 當有新顧客加入商場會員時，我們該如何即時判斷他屬於哪一個群別？
> 
> 請寫出一個 Python 函式 `classify_new_customer(scaler, kmeans_model, income, score)`：
> 1. 輸入新會員的「年收入」與「消費指數」。
> 2. 自動透過已訓練的 `scaler` 做縮放，並使用 `kmeans_model.predict()` 判斷所屬群別。
> 3. 回傳客群名稱與專屬的推薦行銷話術。
> 4. 請測試以下兩位新會員：
>    - 會員甲：年收入 100 千元，消費指數 85 分。
>    - 會員乙：年收入 25 千元，消費指數 15 分。
> ```

## 🛡️ 初學者防雷檢查清單 (AI Code Review Checklist)

- [ ] **是否在計算距離前進行了 `StandardScaler`？**
- [ ] **質心 (Centroids) 畫在散佈圖時，座標尺度是否與散佈點一致？**（若散佈點是用標準化後的數值，質心也必須是標準化後的數值；若是還原尺度，散佈點也必須用原始數值）。
- [ ] **K-Means 是否固定了 `random_state=42`？**（避免初學者每次執行看到的群別編號不同）。
- [ ] **是否具備將演算法結果轉化為「客群畫像與商業策略」的洞察力？**
