# 範例 03：商場客戶價值分群 (集群篇)

本範例以零售商業中最經典的 **「客戶價值畫像與市場區隔 (Customer Segmentation)」** 為核心，引導初學者透過與 AI 的結構化對話，理解**「非監督式學習 (Unsupervised Learning)」** 的概念、如何決定最佳分群數量 K、並為每一群客戶量身打造商業行銷策略。

## 📊 資料集概要 (`customer.csv`)

資料集包含 200 位商場 VIP 會員的人口統計與消費行為指標：

| 欄位名稱 | 數據型態 | 數值範圍 | 商業意義 |
| :--- | :--- | :--- | :--- |
| **性別** | 類別型 (string) | 男 / 女 | 會員生理性別 |
| **年齡** | 數值型 (int64) | 18 ~ 70 歲 | 會員年齡層 |
| **收入(千)** | 數值型 (int64) | 15 ~ 137 千元 | 會員年收入水平（千美元／千台幣） |
| **消費指數(1-100)** | 數值型 (int64) | 1 ~ 99 分 | 商場根據消費頻率與總金額評定的消費活躍度（分數越高越愛買） |

> ⚠️ **關鍵不同點**：這份資料**沒有任何「目標標籤 y」**！我們的任務不是預測某個已知的答案，而是要讓演算法自動找出「行為相似的客群」。

---

## 🎯 學習目標

1. **理解非監督式學習與提問規範**：告訴 AI「這份資料沒有 y 標籤」，引導 AI 採用分群（Clustering）演算法而非分類或迴歸。
2. **掌握特徵縮放 (Feature Scaling) 的必要性**：向 AI 提問「為什麼年齡 (18~70) 與收入 (15~137) 在計算歐氏距離時需要標準化？」
3. **探索最佳群數 K**：引導 AI 繪製並解釋「手肘法 (Elbow Method)」與「輪廓係數 (Silhouette Score)」，學會客觀決定最佳群數。
4. **二維與多維分群視覺化**：讓 AI 繪製分群散佈圖，將不同客群標上不同色彩與群中心 (Centroids)。
5. **產出商業畫像與行銷方案**：讓 AI 分析各群的統計均值，給出白話的客群命名（例如「潛力新貴型」、「高收保守型」）與促銷建議。

# 💬 向 AI 提問的五階段實戰手冊 (直接複製發問)

本手冊帶領初學者掌握「非監督式學習 (Unsupervised Learning)」的提問精髓。當你手上有一份顧客資料卻沒有任何標籤時，請依照以下五個階段，逐步將提示詞複製給你的 AI 工具。

---

## 📌 提問心法：初學者在非監督學習常踩的雷

1. ❌ **誤以為一定要切 Train / Test**
   - 初學者問 AI：「請幫我把資料切成 80% 訓練集和 20% 測試集來做分群。」
   - *觀念矯正*：純探索性分群是為了解讀當前資料庫的群體結構，不需要切分測試集（除非是用於半監督式或生產環境的推論管線）。
2. ❌ **忽略特徵尺度 (Scaling)**
   - K-Means 是基於「幾何歐氏距離」分組。如果不做標準化，數值範圍大的欄位（如年收入 100）會完全壓制數值範圍小的欄位（如年齡 20）。
3. ❌ **隨便拍腦袋決定群數 K**
   - 必須透過「手肘法」或「輪廓係數」等客觀指標，請 AI 輔助找出最合理的群數。

## 🛠️ 階段 2：客觀決定最佳群數 K (手肘法與輪廓分析)

初學者最常問的問題就是：「我怎麼知道該分成 3 群、4 群還是 5 群？」

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 我想客觀決定最佳分群數 K。
> 
> 請提供 Python 程式碼，測試 K=2 到 K=9：
> 1. 先使用 `StandardScaler` 對「收入(千)」與「消費指數(1-100)」進行標準化。
> 2. 計算每個 K 的「組內平方和 (Inertia / WCSS)」，並繪製「手肘法折線圖 (Elbow Method)」。
> 3. 計算每個 K 的「輪廓係數 (Silhouette Score)」，並繪製對應折線圖。
> 
> 【指標白話解說】：
> 請向我這個初學者解釋：
> - 什麼叫「手肘點 (Elbow Point)」？圖形轉折處代表什麼幾何意義？
> - 輪廓係數 (Silhouette Score) 的數值範圍是多少？分數越高代表什麼？
> - 綜合這兩張圖，你推薦我們將顧客分成幾個群體最合理？
> ```

## 🤖 階段 3：執行 K-Means 演算法與視覺化

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 根據手肘法與輪廓係數，我們決定設定 K=5。
> 
> 請提供 Python 程式碼：
> 1. 使用 `sklearn.cluster.KMeans(n_clusters=5, random_state=42)` 進行分群。
> 2. 將分群標籤（0 到 4）存回原始 DataFrame 的新增欄位 `群別`。
> 3. 繪製精美的 5 群彩色散佈圖，並用明顯的紅色大叉叉標示出各群的「質心 (Centroids)」座標。
> 4. 請將質心座標逆轉換 (inverse_transform) 回原始數值（收入與消費指數），方便我們直接理解。
> ```

## 🛡️ 初學者防雷檢查清單 (AI Code Review Checklist)

- [ ] **是否在計算距離前進行了 `StandardScaler`？**
- [ ] **質心 (Centroids) 畫在散佈圖時，座標尺度是否與散佈點一致？**（若散佈點是用標準化後的數值，質心也必須是標準化後的數值；若是還原尺度，散佈點也必須用原始數值）。
- [ ] **K-Means 是否固定了 `random_state=42`？**（避免初學者每次執行看到的群別編號不同）。
- [ ] **是否具備將演算法結果轉化為「客群畫像與商業策略」的洞察力？**
