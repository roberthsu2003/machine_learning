資料集包含 200 位商場 VIP 會員的人口統計與消費行為指標：

| 欄位名稱 | 數據型態 | 數值範圍 | 商業意義 |
| :--- | :--- | :--- | :--- |
| **性別** | 類別型 (`object`) | 男 / 女 | 會員生理性別 |
| **年齡** | 數值型 (`int64`) | 18 ~ 70 歲 | 會員年齡層 |
| **收入(千)** | 數值型 (`int64`) | 15 ~ 137 千元 | 會員年收入水平（千美元／千台幣） |
| **消費指數(1-100)** | 數值型 (`int64`) | 1 ~ 99 分 | 商場依消費頻率與總額評定的消費活躍度（分數越高越愛買） |

> ⚠️ **關鍵不同點**：這份資料**沒有任何「目標標籤 y」**！我們的任務不是預測某個已知的答案，而是要讓演算法自動找出「行為相似的客群邊界」。

當你學會了 `商場客戶分群_集群篇.ipynb` 中的標準化、手肘法與客群畫像觀念後，若想將分群模型打造成**獨立的桌面視窗軟體 (GUI)**，可以直接複製以下這段設計好的 Prompt 貼給任何 AI（ChatGPT / Claude / Gemini / Copilot）。

> 💡 **特別設計**：很多同學手邊沒有「未來的商場新顧客名冊」，因此這個 Prompt 特別要求 AI 在介面中**內建實務客群代表情境按鈕**（例如高收高消費 VIP、年輕潮流族、高收保守族）與**隨機生成顧客資料**功能，讓你不需額外找資料就能立刻進行互動分群！

### 📋 複製給 AI 的專屬 Prompt

```text
請身為資深 Python 與機器學習工程師，為我撰寫一個獨立完整的桌面 GUI 應用程式（單一 .py 檔案）。

【背景與數據說明】
1. 訓練資料集為 `customer.csv`，包含 200 位商場會員的屬性數據。
2. 特徵欄位：
   - 年收入：收入(千)（數值範圍 15 ~ 137 千元）
   - 消費活躍度：消費指數(1-100)（數值範圍 1 ~ 99 分）
   - 年齡：年齡（數值範圍 18 ~ 70 歲）
3. 任務性質：非監督式學習 (Unsupervised Clustering)，無標籤 y。

【功能與架構要求】
1. 機器學習管線 (ML Pipeline)：
   - 使用 Scikit-Learn 的 StandardScaler 與 KMeans (n_clusters=5, init='k-means++', random_state=42)。
   - 啟動程式時自動讀取 CSV 完成特徵標準化與模型訓練，並於介面頂端顯示最佳群數 K=5、輪廓係數 (Silhouette Score) 與群集慣性 (Inertia)。
   - 動態根據各群中心反推平均收入與消費指數，為 5 大群體建立清晰的商業畫像標籤（如：💎 頂級高奢 VIP、⚡ 年輕潮流衝動型、💼 高收精明理財型等）。
2. 圖形使用者介面 (GUI)：
   - 請優先使用 Python 內建的 Tkinter（包含 ttk 現代元件，免安裝額外套件）。
   - 提供年收入（滑桿 + 數值框雙向同步）、消費活躍指數（滑桿 + 數值框雙向同步）與年齡設定。
3. 解決「使用者手邊沒有預測資料」的關鍵功能：
   - 在介面上特別設計「快速預測測試範例 (Preset Scenarios)」區塊，提供 3 組實務顧客情境按鈕（情境 A：高收高消費 VIP、情境 B：年輕衝動潮流族、情境 C：高收入保守高資產）一鍵帶入參數。
   - 同時提供一個「隨機顧客按鈕」，隨機在合理範圍內產生顧客特徵，點擊即帶入輸入框。
4. 結果展示面板：
   - 點擊「判定客群歸類與行銷方案」按鈕後，以醒目大字體顯示該顧客歸屬之客群標籤（例：分群歸類：💎 頂級高奢 VIP 客群）。
   - 提供詳細報告文字框，顯示輸入參數、所屬群代號、群中心代表特徵，以及針對該客群量身打造的精準行銷與 CRM 促銷策略建議。
5. 程式碼品質：
   - 包含完整的繁體中文註解、良好的例外狀況處理（如檔案不存在或輸入異常時跳出友善提示對話框）。
```
