## 💡 為什麼採用「程式儲存格 ＋ AI 互動儲存格」的設計？

過去如果完全讓外部 AI 從無到有自由生成程式碼，常因各家 AI 表現不一（有些模型一次全寫完、有些遺漏資料切分、有些套件版本不合）而導致學習體驗非常不穩定。

因此，本範例採用了最穩健、高品質的學習架構：
1. **保證可執行的穩定基底**：我們已經在 [鐵達尼號生存預測_分類篇.ipynb](./鐵達尼號生存預測_分類篇.ipynb) 中為你依序寫好了標準的機器學習程式儲存格（經過完整測試，絕無語法報錯）。
2. **段段有解說**：每個程式儲存格的**正下方**，都緊接著一個專屬的文字儲存格，詳細說明「這段程式在做什麼」。
3. **內建豐富的 AI 伴學對話小抄 (Prompt)**：每個文字儲存格依據該步驟學生應該掌握的核心觀念，提供多維度的提問提示詞（包含觀念深入拆解、統計陷阱防範、歷史背景解讀與程式碼客製修改），你可以自由挑選並複製貼給 AI！

## 📊 資料集介紹 (`titanic.csv`)

📥 **資料集直接下載**：[titanic.csv (點此下載或於瀏覽器直接開啟)](https://raw.githubusercontent.com/roberthsu2003/machine_learning/main/AI%E6%8F%90%E5%95%8F%E8%88%87%E6%A9%9F%E5%99%A8%E5%AD%B8%E7%BF%92%E5%AF%A6%E6%88%B0/02_%E9%90%B5%E9%81%94%E5%B0%BC%E8%99%9F%E7%94%9F%E5%AD%98%E9%A0%90%E6%B8%AC_%E5%88%86%E9%A1%9E%E7%AF%87/titanic.csv) ｜ 本機相對路徑：[`titanic.csv`](./titanic.csv)

資料集包含 1,313 位乘客的人口統計特徵、艙等票價資訊與生還狀態：

| 欄位名稱 | 數據型態 | 缺失值狀況 | 欄位含義與特徵價值評估 |
| :--- | :--- | :--- | :--- |
| **pclass** | 類別型 (`object`) | 無缺失 | 艙等（`1st`, `2nd`, `3rd`，關鍵社經地位特徵） |
| **survived** | 數值型 (`int64`) | 無缺失 | **預測目標 (y)**：`1` 代表生還、`0` 代表遇難（生還率約 34%） |
| **sex** | 類別型 (`object`) | 無缺失 | 生理性別（`male`, `female`，歷史上婦孺優先政策的關鍵特徵） |
| **age** | 數值型 (`float64`) | 680 筆缺失 | 乘客年齡（數值型，需中位數補齊） |
| **embarked** | 類別型 (`object`) | 492 筆缺失 | 登船港口（`Southampton`, `Cherbourg`, `Queenstown`，需眾數補齊） |
| **boat** | 類別型 (`object`) | 966 筆缺失 | **⚠️ 致命陷阱**：救生艇編號（事後才發生的作弊特徵，會引發 Data Leakage） |

## 🖥️ 進階專題：向 AI 索取「完整流程 ＋ 桌面 GUI 應用程式」

當你學會了 `鐵達尼號生存預測_分類篇.ipynb` 中的缺失值處理、Pipeline 與機率推論觀念後，若想將分類模型打造成**獨立的桌面視窗軟體 (GUI)**，可以直接複製以下這段設計好的 Prompt 貼給任何 AI（ChatGPT / Claude / Gemini / Copilot）。

> 💡 **特別設計**：很多同學手邊沒有「未來的預測乘客名冊」，因此這個 Prompt 特別要求 AI 在介面中**內建歷史代表乘客情境按鈕**（例如頭等艙名媛、二等艙紳士、三等艙移工少年）與**隨機生成乘客資料**功能，讓你不需額外找資料就能立刻進行互動預測！

### 📋 複製給 AI 的專屬 Prompt

```text
請身為資深 Python 與機器學習工程師，為我撰寫一個獨立完整的桌面 GUI 應用程式（單一 .py 檔案）。

【背景與數據說明】
1. 訓練資料集為 `titanic.csv`，包含 1,313 筆鐵達尼號乘客名冊。
2. 特徵欄位：
   - 數值特徵：age（乘客年齡，有缺失值，需中位數補齊並標準化）
   - 類別特徵：pclass（1st, 2nd, 3rd）、sex（female, male）、embarked（Southampton, Cherbourg, Queenstown，需眾數補齊並 One-Hot 編碼）
   - 嚴格排除作弊欄位：boat（救生艇號碼）、room、ticket 等事後資訊，嚴防資料洩漏。
3. 目標預測變數：survived（1 代表生還，0 代表遇難，二元分類）

【功能與架構要求】
1. 機器學習管線 (ML Pipeline)：
   - 使用 Scikit-Learn 的 Pipeline 與 ColumnTransformer。
   - 包含 SimpleImputer、StandardScaler 與 OneHotEncoder。
   - 採用邏輯迴歸 (LogisticRegression) 作為分類模型。
   - 啟動程式時自動讀取 CSV 進行分層切分 (train_test_split 8:2, stratify=y) 並完成模型訓練，於介面頂端顯示模型評估指標（準確率 Accuracy, Precision, Recall, ROC-AUC）。
2. 圖形使用者介面 (GUI)：
   - 請優先使用 Python 內建的 Tkinter（包含 ttk 現代元件，免安裝額外套件）。
   - 提供艙等 (Combobox)、生理性別 (Combobox)、年齡（滑桿 + 數值框雙向同步）與登船港口 (Combobox)。
3. 解決「使用者手邊沒有預測資料」的關鍵功能：
   - 在介面上特別設計「快速預測測試範例 (Preset Scenarios)」區塊，提供 3 組具代表性的歷史乘客情境按鈕（情境 A：頭等艙名媛、情境 B：二等艙紳士、情境 C：三等艙移工少年）一鍵帶入參數。
   - 同時提供一個「隨機乘客按鈕」，隨機在合理範圍內產生乘客特徵，點擊即帶入輸入框。
4. 預測結果顯示面板：
   - 點擊「計算生還機率與命運判定」按鈕後，以醒目大字體顯示判定結果（生還 / 遇難）與生還機率百分比（例：生還機率估算：87.8%）。
   - 提供詳細報告文字框，顯示輸入參數清單、歷史「婦孺優先」政策背景解讀與社經艙等對救生資源分配的關鍵影響。
5. 程式碼品質：
   - 包含完整的繁體中文註解、良好的例外狀況處理（如檔案不存在或輸入異常時跳出友善提示對話框）。
```
