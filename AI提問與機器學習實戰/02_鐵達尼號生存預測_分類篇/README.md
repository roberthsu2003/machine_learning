## 📊 資料集概要 (`titanic.csv`)

資料集包含 1,313 位乘客的人口統計特徵、艙等票價資訊與生還狀態：

| 欄位名稱 | 數據型態 | 缺失值狀況 | 欄位含義與特徵價值評估 |
| :--- | :--- | :--- | :--- |
| `row.names` | int64 | 無 | 乘客序號（無預測價值，應剔除） |
| `pclass` | object | 無 | 艙等（`1st`, `2nd`, `3rd`，關鍵社經地位特徵） |
| `survived` | int64 | 無 | **預測目標 (y)**：`1` 代表生還、`0` 代表遇難（生還率約 34%） |
| `name` | object | 無 | 乘客姓名（高基數文字，應剔除） |
| `age` | float64 | 680 筆缺失 | 乘客年齡（數值型，需中位數補值） |
| `embarked` | object | 492 筆缺失 | 登船港口（`Southampton`, `Cherbourg`, `Queenstown`） |
| `home.dest` | object | 559 筆缺失 | 乘客住址／目的地（應剔除） |
| `room` / `ticket` | object | 缺失 > 90% | 客艙房號與票號（缺失比例過高，應剔除） |
| `boat` | object | 966 筆缺失 | **⚠️ 致命陷阱**：救生艇編號（事後才發生的作弊特徵，會引發 Data Leakage） |
| `sex` | object | 無 | 生理性別（`male`, `female`，歷史上婦孺優先政策的關鍵特徵） |

## 🎯 學習目標

1. **學會向 AI 諮詢「特徵合理性審查」**：讓 AI 扮演嚴格的資料科學家，找出哪些欄位是無效特徵、哪些是具有「未來資訊洩漏」的作弊欄位（例如 `boat`）。
2. **缺失值補齊 (Imputation) 提問**：學習如何引導 AI 使用 `SimpleImputer` 處理年齡與類別特徵缺失，並整合成 Scikit-Learn Pipeline。
3. **分層抽樣 (Stratified Split)**：面對 34% vs 66% 的偏斜分佈，如何請 AI 採用分層抽樣，確保訓練集與測試集比例一致。
4. **分類評估指標深度解讀**：理解為什麼只看「準確率 (Accuracy)」是不夠的，學會要求 AI 用白話文解釋「混淆矩陣 (Confusion Matrix)」、「精確率 (Precision)」、「召回率 (Recall)」與「F1-Score」。
5. **虛擬乘客生存機率試算**：建立生還機率預測函式，輸入不同性別、年齡與艙等的假設乘客，算出其生還機率百分比。

# 💬 向 AI 提問的五階段實戰手冊 (直接複製發問)

本手冊教導初學者如何面對「有缺失值、有類別不平衡、甚至隱藏作弊特徵」的真實世界分類數據。請依照以下五個階段，逐步將提示詞複製給你的 AI 工具。

---

## 📌 提問心法：分類問題的致命陷阱

1. ❌ **陷阱一：把未來發生的事當成特徵（資料洩漏 Data Leakage）**
   - 資料中有一個欄位叫 `boat`（救生艇號碼）。初學者直接把所有欄位塞給 AI，AI 做出高達 99% 準確率，但這在實務上完全沒有意義（船剛撞冰山時根本不知道誰會上哪艘救生艇）。
2. ❌ **陷阱二：被準確率 (Accuracy) 欺騙**
   - 資料中只有 34% 人生還，如果模型「什麼都不學，全部預測死亡」，準確率居然也有 66%！因此必須逼 AI 解釋 **Recall（召回率）** 與 **Precision（精確率）**。
3. ❌ **陷阱三：隨機切分導致比例偏斜**
   - 分類問題切分 Train/Test 時，必須提醒 AI 加上 `stratify=y`。

## 🛠️ 階段 2：缺失值填補與 Pipeline 建構

> [!TIP]
> **📋 複製這段提示詞給 AI：**
> 
> ```markdown
> 現在我們要對特徵進行前處理。我注意到：
> - `age` 是連續數值，有許多空值。
> - `pclass`, `sex`, `embarked` 是類別型欄位，且 `embarked` 也有空值。
> 
> 請教導我並寫出 Scikit-Learn 處理程式碼：
> 1. 數值特徵 (`age`)：請使用 `SimpleImputer(strategy='median')` 填補中位數，並搭配 `StandardScaler` 標準化。為什麼年齡補值建議用中位數而非平均數？
> 2. 類別特徵：請用 `SimpleImputer(strategy='most_frequent')` 補眾數，並用 `OneHotEncoder(handle_unknown='ignore')` 編碼。
> 3. 使用 `ColumnTransformer` 將兩者封裝。
> 4. 切分資料集：80% 訓練集、20% 測試集。請務必加上 `stratify=y` 與固定 `random_state=42`。請向我解釋為什麼分類問題必須加上 `stratify=y`？
> ```
